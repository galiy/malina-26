# Дапаможнік карыстальніка «Маліна»

«Маліна» — прылада для кантролю і кіравання энергаабсталяваннем: МАП, КЭС,
акумулятарнымі батарэямі з BMS і сеткавымі інвертарамі. Кіраванне — праз
веб-адмінку, даступную з тэлефона, планшэта або камп'ютара па сетцы.

Дакументацыя пабудавана па старонках меню. Калі не ведаеце, з чаго пачаць, адкрыйце
раздзел «З чаго пачаць».

![Галоўная старонка: плашкі падключаных прылад](img/main/home.png)
