# Тармоқ созлаш

![Тармоқ созлаш: режимлар ва параметрлар](../img/network/screen.png)

## Қачон бу ерга кирасиз

- Қурилма тармоқда қандай ишлашини танлаш керак: ўз Wi-Fi тармоғини яратади ёки
  мавжуд тармоққа уланади.
- Кириш нуқтаси номи ёки паролини ўзгартириш керак.
- Кириш нуқтаси клиентлари интернетга чиқиши учун.
- Адресларни ўзгартириш ёки симли портда DHCP тарқатишни ўчириш керак.

## Иккита режим

Қурилма икки режимдан бирида ишлайди. Алмаштириш — вкладка танлаш ва
«Сақлаш». Иккала созламалар тўплами алоҳида сақланади ва алмаштиришда
йўқолмайди.

### Кириш нуқтаси

Қурилма Wi-Fi тармоғини яратади, адреслар тарқатади ва клиентларни симли порт
орқали интернетга чиқариши мумкин.

Майдонлар:

- **SSID** — тармоқ номи.
- **Пароль** — WPA2 пароли, кам деганда 8 белги.
- **Канал** — `auto` ёки 1–11.
- **Мамалакат** — Wi-Fi учун регион.
- **Wi-Fi ни ўчириш** — Ethernet уланганда кириш нуқтасини ўчириш ва кабель
  узилгандан кейин яна кўтариш.
- **Бизнинг тармоқ / DHCP** — қурилма IP-адреси, маска, клиентлар учун адрес
  пулининг бошланиши ва охири.
- **Ethernet** — `DHCP` ёки `static`; статик режим учун — IP, маска, шлюз,
  DNS.
- **Интернет-транзит (NAT)** — клиентларга Ethernet орқали интернетга чиқишга
  рухсат бериш. Сукунат бўйича ёқилган.
- **Captive-portal** — уланганда клиентларга кириш саҳифасини таклиф қилиш. Сукунат
  бўйича ёқилган.

### Wi-Fi клиент

Қурилма ташқи Wi-Fi тармоғига уланади, симли порт эса клиентлар учун локаль
тармоққа айланади.

Майдонлар:

- **SSID** ва **Сканерлаш** — ташқи тармоқни танлаш.
- Ташқи тармоқ **Пароль**и.
- **IP STA** — `DHCP` ёки `static`; статик режим учун — IP, маска, шлюз, DNS.
- **Бизнинг тармоқ / DHCP (eth0)** — қурилма IP-адреси, маска, адрес пули.
- **eth0 да DHCP тарқатиш** — симли клиентларга адрес бериш-бермаслик. Сукунат
  бўйича ёқилган.

## Режимни қандай ўзгартириш

1. «Система → Тармоқ созлаш»ни очинг.
2. Керакли режим вкладкасини танланг.
3. Майдонларни тўлдиринг.
4. «Сақлаш»ни босинг.

Тармоқ қайта ишга тушади ва жорий уланиш узилиши мумкин. Сақлагандан кейин қайта
уланинг:

- кириш нуқтаси режимида — қурилма Wi-Fi сига, қурилма адреси сукунат бўйича
  `10.10.100.254`;
- клиент режимида — ташқи Wi-Fi тармоғига ва қурилманинг янги адресини роутер
  клиентлари рўйхатидан топинг.

«Тиклаш» тугмаси майдонларни сўнгги сақланган қийматларга қайтаради, заводск
қийматларга эмас.

## Кириш нуқтаси паролини қандай ўзгартириш

1. «Кириш нуқтаси» вкладкасини очинг.
2. Паролни ўзгартиринг (кам деганда 8 белги).
3. Сақланг ва тармоққа қайта уланинг.

## Қандай текшириш

- «Тизим ҳақида маълумот → Тармоқ ҳолати» доимий ва жорий режимни кўрсатади.
- Тарқатиш ёқилган бўлса клиентлар адреслар олади.
- NAT ёқилганда кириш нуқтаси клиентлари Ethernet орқали интернетга чиқади.

## Агар иш бермаса

- **Сақлагандан кейин кириш йўқолди** — адрес ёки режим ўзгарган. Қурилмани янги
  адресдан қидиринг ёки кириш нуқтасига уланинг.
- **Ташқи Wi-Fi га уланмаяпти** — SSID, пароль ва тармоқ масофасини текширинг.
  Муваффақиятсизликдан кейин қурилма ўзи кириш нуқтасини кўтаради, сиз созламаларни
  тузатишингиз учун.
- **Кириш нуқтаси клиентларида интернет йўқ** — интернетли уланган Ethernet ва
  ёқилган NAT керак.
- **Симли клиентлар адрес олмаяпти** — «eth0 да DHCP тарқатиш»ни ва «Маълумот»да
  «DHCP монитори» ҳолатини текширинг. Бегона DHCP аниқланганда тарқатиш атайлаб
  тўхтатилади.
- **Кириш нуқтаси кабель уланганда йўқолди** — «Wi-Fi ни ўчириш» опцияси шундай
  ишлайди. Уни ўчиринг ёки кабелни чиқаринг.
- **Кириш нуқтаси кўринмаяпти** — икки дақиқагача кутинг, режимни ва «Wi-Fi ни
  ўчириш» опциясини текширинг. Ёрдам бермаса — қурилмани қайта юкланг.
