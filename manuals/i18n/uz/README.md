# «Малина» фойдаланувчи қўлланмаси

«Малина» — энергия ускуналарини назорат қилиш ва бошқариш қурилмаси: МАП, КЭС,
BMS билан аккумулятор батареялари ва тармоқ инверторлари. Бошқариш — тармоқ орқали
телефон, планшет ёки компьютердан очиладиган веб-админка орқали амалга оширилади.

Ҳужжатлар меню саҳифалари бўйича тузилган. Қаердан бошлашни билмасангиз,
«Қаердан бошлаш керак» бўлимини очинг.
