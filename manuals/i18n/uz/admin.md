# Администратор йўриқномаси

Бу саҳифа — қурилмага хизмат кўрсатувчи киши учун: SSH орқали кириш, киришни
тиклаш, хизматлар ва журналларни бошқариш. Қурилмалар билан оддий ишлаш учун у
керак эмас.

## SSH орқали кириш

Қурилма тармоғига (кириш нуқтаси ёки умумий тармоқ) уланинг ва бажаринг:

```
ssh malina@<қурилма-манзили>
```

- Кириш нуқтаси тармоғида манзил — `10.10.100.254`.
- Умумий тармоқда — қурилма DHCP орқали олган ёки қўлда берилган манзил.

Стандарт парол — `malina-26`. У `root` фойдаланувчиси учун ҳам амал қилади.

Парол «Тизим параметрлари → Паролни ўзгартириш» саҳифасида ўзгартирилади ва дарҳол
веб-кириш ҳамда SSH учун амал қилади.

## Агар парол йўқолган бўлса

- Агар SSH кириш сақланган бўлса, киринг ва паролни «Тизим параметрлари» веб-
  саҳифаси орқали ўзгартиринг.
- Агар веб-парол ҳам, SSH пароли ҳам йўқолган бўлса, қурилмани қайта ўрнатмасдан
  киришни тиклашнинг мунтазам усули йўқ. Қурилма учун масъул бўлган шахсга
  мурожаат қилинг.

## Хизматларни бошқариш

«Тизим → Хизматлар»ни очинг.

- **«Малина»** таби — подтизим хизматлари. Уларни ишга тушириш ва тўхтатиш мумкин.
- **«Тизим»** таби — операцион тизим хизматлари, фақат кўриш.

Тўхтатишдан олдин хизмат қаторидаги изоҳни ўқинг. Баъзи хизматларни тўхтатиб
бўлмайди:

- тармоқ хизмати — админка ва кириш нуқтасига кириш йўқолади;
- веб-админканинг ўзи — интерфейс ёпилади;
- ОТнинг муҳим хизматлари — қурилма ишини бузиши мумкин;
- автоматика бошқарадиган таймерлар ва хизматларни қўлда ишга тушириш шарт эмас.

Тармоқ хизмати тўхтатилгач кириш йўқолса, қурилмани қайта юкланг.

## Қайта юклаш ва ўчириш

- «Тизим параметрлари → Қувват бошқаруви» — қайта юклаш ва тўғри ўчириш.
- «Хизматлар → Малинани қайта юклаш» — худди шу нарса.

Қайта юклашдан сўнг кутиш саҳифаси очилади. У икки дақиқагача мавжудликни
текширади. Агар кўпроқ бўлса — саҳифани қўлда янгиланг.

Ўчиришда тўлиқ тўхташини кутинг ва фақат кейин қувватни узинг.

## Тармоқ: режимлар ва киришни тиклаш

- **1-режим «Кириш нуқтаси»** — қурилма Wi-Fi тармоғини яратади. Админка шу тармоқдаги
  қурилма манзилида мавжуд (стандарт `10.10.100.254`). Симли порт умумий тармоққа
  уланади.
- **2-режим «Wi-Fi мижоз»** — қурилма ташқи Wi-Fi тармоғига уланади. Админка қурилма
  шу тармоқда олган манзилда мавжуд. Симли мижозлар учун локал тармоқ `eth0`да
  қолади.

Режим алмашганда кириш манзили ўзгаради. Сақлашдан сўнг кириш йўқолса, қурилмани
роутердаги янги манзилидан қидиринг. Ташқи тармоққа уланиш амалга ошмаса, қурилма
ўзи вақтинча кириш нуқтасини кўтаради.

Агар симли сегментда бегона DHCP-сервер аниқланса, қурилма манзил тарқатишни
тўхтатади, лекин ўз манзилида мавжуд бўлиб қолади. Бегона сервер йўқолгач, тарқатиш
автоматик қайта бошланади.

## Журналлар

«Тизим → Тизим ҳақида маълумот → Журналлар» — тизим журналларини кўриш. Файллар
рўйхати белгиланган, журналлар фақат ўқиш учун.

Журналларни ташқи серверга юбориш учун манзилни «Тизим параметрлари →
Журналга ёзиш»да кўрсатинг. Майдон бўш бўлса, тармоқ созламаларидаги манзил
ишлатилади.

## Вақт

- Қурилма вақт минтақаси «Тизим параметрлари → Хост»да ўзгартирилади.
- МАП вақти қурилма билан ҳар 10 дақиқада синхронлаштирилади, агар фарқ бир дақиқадан
  ошса. Худди шу жойда, «МАП вақти синхронлаштириши»да ўчирилади.

## Мониторинг

«Тизим параметрлари → Мониторинг» ташқи қабул қилгичга даврий билдиришномаларни
юборишни ёқади. Қабул қилгич IP-манзили ва даврни кўрсатиш керак. Мониторинг керак
бўлмаса, уни ўчириб қолдиринг.

## API

- [Native API: lists, raws](api-native.md) — токенлар, рўйхатлар, хом контрактлар,
  ёзиш ва статистика.
- [Legacy API](api-legacy.md) — бутун эски API ва «Мастер-Тугун» билан мослик.
- Native-API Bearer-токен ёки cookie ишлатади. Legacy-ўқиш авторизациясиз очиқ,
  legacy-ёзиш — HTTP Basic (`malina` + парол).

## Носозликларда нима қилиш керак

1. «Тизим ҳақида маълумот»ни очинг: ҳарорат, қувват, диски ва носоз хизматларни
   текширинг.
2. «Хизматлар»ни очинг: хизматлар ҳолатини кўринг.
3. «Журналлар»ни очинг: хато хабарларини топинг.
4. Қурилма қотиб қолган бўлса — қайта юкланг.
5. Муаммо такрорланса — тавсиф ва вақтни сақлаб, дастурчига мурожаат қилинг.
