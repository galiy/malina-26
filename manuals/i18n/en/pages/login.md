# Sign in

![Sign in to the web admin](../img/start/login.png)

## When to come here

You have opened the device address but have not signed in yet — or you want to change the interface language before signing in.

## What you will see

One “Password” field, a “Sign in” button, a show-password eye, and a language switch in the top right. The “?” sign next to the language opens the help.

## How to sign in

1. Enter the password. The username is not requested — it is fixed.
2. Press “Sign in”.
3. If the password is correct, the main page opens.

The default password is `malina-26`. Change it at the first opportunity on the “System parameters” page.

The eye button shows the entered password — handy if you are unsure about the keyboard layout.

## How to check it worked

After a correct password, the main page opens. If the sign-in page remains with a red message — the password is incorrect.

## Language

The language switch is in the top right. The choice is remembered and applies to all pages. The language affects only the interface; the device settings do not change.

## If you cannot sign in

- **“Invalid password”** — check the keyboard layout, case, and Caps Lock.
- **Signed out after changing the password** — this is normal: all sessions are ended. Sign in with the new password.
- **Sign-in does not persist** — the browser must accept cookies; private mode can interfere.
- **Forgot the password** — see the [Administrator manual](../admin.md).
