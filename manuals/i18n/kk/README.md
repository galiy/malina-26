# «Малина» пайдаланушы нұсқаулығы

«Малина» — энергия жабдығын бақылау және басқару құрылғысы: МАП, КЭС, BMS-і бар
аккумулятор батареялары және желілік инверторлар. Басқару — желі бойынша телефоннан,
планшеттен немесе компьютерден қолжетімді веб-админка арқылы.

Құжаттама мәзір беттері бойынша құрылған. Неден бастау керектігін білмесеңіз,
«Неден бастау керек» бөлімін ашыңыз.

![Басты бет: қосылған құрылғылардың плашкалары](img/main/home.png)
