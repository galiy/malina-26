# მომხმარებლის სახელმძღვანელო «მალინა»

«მალინა» — მოწყობილობა ენერგოაღჭურვილობის კონტროლისა და მართვისთვის: MAP, KES,
BMS-ით აკუმულატორის ბატარეები და ქსელური ინვერტორები. მართვა ხორციელდება
ვებ-ადმინკის საშუალებით, რომელიც ხელმისაწვდომია ტელეფონიდან, პლანშეტიდან ან
კომპიუტერიდან ქსელით.

დოკუმენტაცია აგებულია მენიუს გვერდებად. თუ არ იცით, საიდან დაიწყოთ, გახსენით განყოფილება
«საიდან დავიწყოთ».

![მთავარი გვერდი: მიერთებული მოწყობილობების ბლოკები](img/main/home.png)
