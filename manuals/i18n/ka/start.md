# საიდან დავიწყოთ

ეს გვერდი — პირველი ჩართვისთვის. ის გაგიძღვებათ კვების მიწოდებიდან პირველი
პარამეტრების დაყენებამდე, რომლებიც ღირს დაუყოვნებლივ გაკეთება.

![შესვლის გვერდი](img/start/login.png)

## რა დაგჭირდებათ

- მოწყობილობა «მალინა» კვების ბლოკით.
- ტელეფონი ან ნოუთბუქი Wi-Fi-ით.
- Ethernet-ის კაბელი — სურვილისამებრ, თუ საჭიროა მოწყობილობის საერთო ქსელთან
  დაკავშირება.

## ნაბიჯი 1. ჩართოთ და დაელოდოთ

შეაერთეთ კვება. მოწყობილობა იტვირთება და თავად ქმნის Wi-Fi წვდომის წერტილს.
ეს დაახლოებით ერთ წუთს იღებს, იშვიათ შემთხვევაში — ორ წუთამდე. არაფრის დაჭერა არ
არის საჭირო.

## ნაბიჯი 2. დაუკავშირდეთ Wi-Fi-ს

ტელეფონზე ან ნოუთბუქზე გახსენით Wi-Fi ქსელების სია და დაუკავშირდით ქსელს:

- ქსელის სახელი — **Malina**;
- პაროლი — **malina-26**.

თუ მოწყობილობა უკვე დაყენებულია და ქსელის სახელი შეცვლილია, გამოიყენეთ ახალი სახელი.

## ნაბიჯი 3. გახსნათ ადმინკა

დაკავშირების შემდეგ სისტემამ შეიძლება შემოგთავაზოთ «ქსელში შესვლა» — დათანხმდით.
ეს არის ადმინკაში შესვლის გვერდი.

თუ შეთავაზება არ გამოჩნდა, გახსენით ბრაუზერი და შეიყვანეთ მისამართი:
**http://10.10.100.254/**

## ნაბიჯი 4. შესვლა

შეიყვანეთ პაროლი **malina-26**. მომხმარებლის სახელი არ იკითხება.

ინტერფეისი ნაგულისხმევად ინგლისურია. ენის შესაცვლელად გამოიყენეთ გადამრთველი
ზედა მარჯვნივ — არჩევანი დაიმახსოვრდება.

## ნაბიჯი 5. დარწმუნდეთ, რომ ყველაფერი მუშაობს

გახსენით «სისტემა → ინფორმაცია სისტემის შესახებ». უნდა ნახოთ მონაცემები ჰოსტზე,
პროცესორზე, მეხსიერებაზე, დისკებსა და ქსელზე — ისინი ავტომატურად განახლდება.

თუ მოწყობილობები (MAP, KES, BMS, ინვერტორები) ჯერ არ არის მიერთებული, მთავარი
გვერდი და მოწყობილობების განყოფილებები ცარიელი იქნება. ეს ნორმალურია, გაუმართაობა არ არის.

## ნაბიჯი 6. დაუყოვნებლივ შეცვალოთ პაროლები

ნაგულისხმევი პაროლები ყველამ იცის, ამიტომ საჭიროა მათი შეცვლა.

1. გახსენით «სისტემა → სისტემის პარამეტრები → პაროლის შეცვლა».
2. შეიყვანეთ ახალი პაროლი ორჯერ (მინიმუმ 4 სიმბოლო) და შეინახეთ.

ეს პაროლი მოქმედებს ვებ-ადმინკასა და SSH-ზე — მათ შორის მომხმარებლისთვის `root`.
შეცვლის შემდეგ ყველა სესია დასრულდება — შედით ხელახლა.

წვდომის წერტილის პაროლი იცვლება ცალკე: «სისტემა → ქსელის პარამეტრები →
რეჟიმი 1 → პაროლი». მინიმუმ 8 სიმბოლო.

## ნაბიჯი 7. შეამოწმოთ ძირითადი პარამეტრები

- **მოწყობილობის სახელი** — «სისტემის პარამეტრები → ჰოსტი».
- **დროის ზონა** — იქვე. მასზეა დამოკიდებული დრო გვერდებზე და ისტორიაში.
- **ჟურნალების გადაგზავნა** — «სისტემის პარამეტრები → ლოგირება», თუ გაქვთ
  syslog-სერვერი. ცარიელი ველი — მისამართის ავტომატურად აღება ქსელიდან (DHCP).
- **MAP-ის დროის სინქრონიზაცია** — «სისტემის პარამეტრები → MAP-ის დროის
  სინქრონიზაცია».
- **მოწყობილობები** — თუ MAP ჯერ არ არის განსაზღვრული, შეამოწმეთ კავშირი. KES და
  BMS ნაგულისხმევად არ იკითხებიან — ჩართეთ ისინი პარამეტრების გვერდებზე.

## დაკავშირება კაბელით

თუ მოწყობილობას საერთო ქსელთან დააკავშირებთ Ethernet-ის კაბელით, ის მიიღებს
მისამართს ავტომატურად. იპოვეთ ეს მისამართი თქვენი როუტერის კლიენტების სიაში და გახსენით
`http://<მისამართი>/` ბრაუზერში.

სახელით `malina.local` მისამართი არ არის გარანტირებული — გამოიყენეთ IP-მისამართი.

ამავდროულად ხელმისაწვდომი რჩება წვდომის წერტილითაც.

## მოწყობილობის დაკავშირება გარე Wi-Fi-თან

თუ საჭიროა, რომ «მალინა» თავად დაუკავშირდეს თქვენს Wi-Fi ქსელს:

1. გახსენით «სისტემა → ქსელის პარამეტრები» და აირჩიეთ რეჟიმი «Wi-Fi კლიენტი».
2. მიუთითეთ ქსელი (შეგიძლიათ დააჭიროთ «სკანირება») და პაროლი.
3. შეინახეთ პარამეტრები.

შენახვის შემდეგ წვდომის მისამართი შეიცვლება: მოწყობილობა გახდება გარე ქსელის
კლიენტი. იპოვეთ მისი ახალი მისამართი როუტერის კლიენტების სიაში. ადგილობრივი ქსელი
`10.10.100.x` გადავა საკაბელო პორტზე.

თუ დაკავშირება ვერ მოხერხდა, მოწყობილობა თავად შექმნის წვდომის წერტილს **Malina**,
რომ შეძლოთ დაბრუნება და პარამეტრების გასწორება.

## თუ რამე არასწორად წავიდა

- **Malina-ს ქსელი არ ჩანს.** დაელოდეთ ორ წუთს. შეამოწმეთ, რომ მოწყობილობა
  ჩართულია. თუ ქსელი პარამეტრების ცვლილების შემდეგ გაქრა — დაუკავშირდით კაბელით ან
  გადატვირთეთ მოწყობილობა.
- **გვერდი არ იხსნება.** დარწმუნდით, რომ ქსელში `Malina` ხართ და შეიყვანეთ სწორედ
  `http://10.10.100.254/`.
- **პაროლი არ ერგება.** შეამოწმეთ კლავიატურის განლაგება და რეგისტრი. თუ პაროლი
  შეცვალეთ და დაივიწყეთ — იხ. [«ადმინისტრატორის ინსტრუქცია»](admin.md).
- **ქსელის რეჟიმის შეცვლის შემდეგ წვდომა გაქრა.** იპოვეთ ახალი მისამართი როუტერში
  ან დაუკავშირდით წვდომის წერტილს, რომელსაც მოწყობილობა წარუმატებლობისას ქმნის.

## პირველი გაშვების ჩეკ-სია

- [ ] დავუკავშირდი ქსელს `Malina`;
- [ ] გავხსენი ადმინკა და შევედი;
- [ ] ავირჩიე ენა;
- [ ] შევცვალე ვებ-ადმინკისა და SSH-ს პაროლი;
- [ ] შევცვალე წვდომის წერტილის სახელი და პაროლი;
- [ ] შევამოწმე მოწყობილობის სახელი და დროის ზონა;
- [ ] ვნახე «ინფორმაცია სისტემის შესახებ»;
- [ ] საჭიროებისამებრ დავაყენე ქსელი და ჩავრთე საჭირო მოწყობილობები.
