# MAP

![MAP 页面：面板](../img/map/screen.png)

## 什么时候来这里

- 需要了解 MAP 此刻的状态：模式、电网、负载、蓄电池、温度。
- 需要修改参数或下发指令：开启/关闭 MAP、充电、继电器、复位。
- 需要查看设备铭牌和版本。

本页从菜单「MAP」为某台具体的 MAP 打开。如果有多个 MAP，菜单中会列出全部设备。

## 你会看到什么

上方是带型号和序列号的标题，以及「停用更新」复选框。它用于暂停自动刷新数据。最后打开过的标签页会被记住。

页面分为三个标签页。

### 面板

实时模拟图：电网、负载和蓄电池的电压、电流、功率、模式、电量、温度、继电器状态、MAP 时间和最后快照时间。如果接入了 BMS 或并联 MPPT，下方会出现它们的表格。

### 信息

两个子标签页：

- **基本** — 设备铭牌：主板和软件版本、类型、功率、工作电压、充电和电网参数、继电器、BMS/MPPT。
- **系统** — 按分组列出所有参数的表格。名称已标注，数值已换算为常用单位。破折号表示该值对此型号或固件不可用。

### 控制

上方是指令，下方是按分组排列的参数：「发电」、「电网 1」、「电网 2」、「蓄电池」、「外部设备」、「继电器」、「其他」。

“外部设备”分组用于配置 RS3 端口和外部 BMS/MPPT。RS3 仅在 Titanator 上可用；在 Dominator 上仅显示 BMS/MPPT。

## 如何下发指令

1. 打开「控制」标签页。
2. 点击所需按钮。
3. 如果出现确认提示 — 确认该操作。

指令：

- **开启/关闭 MAP。** 关闭需要确认。
- **开启/停止充电。**
- **继电器 1..N** — 仅当继电器配置为外部控制时可用。Titanator 有三个继电器，Dominator 有两个。面板上的 R1–R3 指示灯始终显示，表示线路状态，即使继电器不可用于控制。
- **复位** — 重启控制器。需要连续三次确认；可在任何一步取消。

## 如何修改参数

1. 在所需分组中找到对应行。
2. 在「值」列中修改数值。
3. 点击行内的「保存」— 或点击「全部保存」以一次写入全部更改。

规则：

- 被修改的行会高亮；
- 不允许的值以红色高亮，且无法保存；
- 行内的「取消」恢复当前值；
- 「全部取消」撤销所有未保存的修改；
- 成功写入后，数值会从 MAP 重新读取；
- 如果你开始编辑某个字段，自动刷新不会覆盖你的输入。

参数旁的「?」图标显示说明。

## 如何确认成功

- 指令已执行：面板上的状态发生了变化。
- 参数已保存：点击「保存」后修改高亮消失，数值已从 MAP 重新读取。
- 页面上没有写入错误。

## 如果没有成功

- **「无连接」** — 数据没有到达。请检查连接和轮询设置；页面会持续重试。
- **值无法保存** — 请检查范围。「?」提示会解释参数；红色高亮表示错误。
- **保存返回错误** — 请重试。如果错误反复出现，检查通信和轮询状态；必要时联系管理员。
- **没有继电器按钮** — 此型号没有继电器，或继电器未切换到外部控制模式。
- **重连后页面「消失」** — 等最多一分钟：页面会自行按序列号找到设备。
- **大量破折号** — 此型号或固件未发布这些值。这不一定是故障。
