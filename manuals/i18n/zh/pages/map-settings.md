# MAP — 设置

![MAP 设置：状态与表单](../img/map-settings/screen.png)

## 什么时候来这里

- MAP 不显示或数据不刷新 — 需要检查轮询是否开启。
- 需要临时关闭 MAP 轮询。
- 需要提高日志详细度以进行诊断。

## 你会看到什么

上方是「设备状态」卡片：设备能看到的所有 MAP。每个都显示标识符、序列号、端口、型号、协议、波特率、状态和最后一次成功轮询的时间。状态「正常」表示数据最近到达过；「无连接」表示设备没有响应。卡片每秒刷新一次。

下方是设置表单。

## 如何开启或关闭轮询

1. 选中或取消选中「启用」。
2. 点击「保存」。

轮询关闭时，服务仍在运行，但 MAP 不会被轮询：新数据不会到达，状态卡片中可能保留最后的状态。

## 如何修改日志级别

选择级别并保存：

- **调试** — 最详细，用于诊断。
- **信息** — 常规模式。
- **警告** — 仅警告。
- **错误** — 仅错误。

默认使用「信息」。详细级别应临时开启：它更快填满日志。

## 如何确认生效

- 保存后出现成功消息。
- 设置立即生效，无需重启服务。
- 状态卡片中 MAP 的状态应保持「正常」，最后成功时间应更新。

## 如果没有成功

- **保存后轮询没有变化** — 请重试保存。如果无效，请在「服务」页检查服务状态。
- **卡片中为「无数据 / 轮询已关闭」** — 启用轮询并保存。
- **MAP 状态为「无连接」** — 请检查线缆、电源和端口；必要时联系管理员。
- **「日志级别无效」** — 请从列表中选择一个值。
