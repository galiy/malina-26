# 网络设置

![网络设置：模式与参数](../img/network/screen.png)

## 什么时候来这里

- 需要选择设备如何在网络中工作：创建自己的 Wi-Fi 网络，还是接入现有网络。
- 需要修改接入点的名称或密码。
- 需要让接入点客户端能够上网。
- 需要修改地址或在有线端口关闭 DHCP 分配。

## 两种模式

设备在两种模式之一中运行。切换方式 — 选择标签页并「保存」。两套设置分别保存，切换时不会丢失。

### 接入点

设备创建 Wi-Fi 网络、分配地址，并可通过有线端口让客户端上网。

字段：

- **SSID** — 网络名称。
- **密码** — WPA2 密码，至少 8 个字符。
- **信道** — `auto` 或 1–11。
- **国家** — Wi-Fi 地区。
- **关闭 Wi-Fi** — 以太网连接期间熄灭接入点，拔掉网线后重新开启。
- **我们的网络 / DHCP** — 设备 IP、掩码、地址池起止。
- **以太网** — `DHCP` 或 `static`；静态模式下 — IP、掩码、网关、DNS。
- **Internet 共享 (经以太网 NAT)** — 允许客户端通过以太网上网。默认为开启。
- **强制门户** — 客户端连接时提供登录页。默认为开启。

### Wi-Fi 客户端

设备接入外部 Wi-Fi 网络，有线端口成为客户端使用的本地网络。

字段：

- **SSID** 和 **扫描** — 选择外部网络。
- 外部网络的 **密码**。
- **STA IP** — `DHCP` 或 `static`；静态模式下 — IP、掩码、网关、DNS。
- **我们的网络 / DHCP (eth0)** — 设备 IP、掩码、地址池。
- **在 eth0 上提供 DHCP** — 是否向有线客户端分配地址。默认为开启。

## 如何切换模式

1. 打开「系统 → 网络设置」。
2. 选择所需模式的标签页。
3. 填写字段。
4. 点击「保存」。

网络会重启，当前连接可能中断。保存后请重新连接：

- 在接入点模式下 — 连接到设备的 Wi-Fi，设备地址默认为 `10.10.100.254`；
- 在客户端模式下 — 连接到外部 Wi-Fi，并在路由器客户端列表中查找设备的新地址。

「恢复」按钮把字段恢复到最近保存的值，而不是出厂值。

## 如何修改接入点密码

1. 打开「接入点」标签页。
2. 修改密码（至少 8 个字符）。
3. 保存并重新连接网络。

## 如何检查

- 「系统信息 → 网络状态」显示固定模式和当前模式。
- 如果分配已开启，客户端会获得地址。
- NAT 开启时，接入点客户端通过以太网上网。

## 如果没有成功

- **保存后失去访问** — 地址或模式已变。请按新地址寻找设备，或连接到接入点。
- **无法接入外部 Wi-Fi** — 请检查 SSID、密码和网络覆盖范围。失败后设备会自行开启接入点，以便你修改设置。
- **接入点客户端没有网络** — 需要已连接且能上网的以太网，以及开启的 NAT。
- **有线客户端拿不到地址** — 请检查「在 eth0 上提供 DHCP」和「系统信息」中的「DHCP 监视」状态。检测到外来 DHCP 时会刻意暂停分配。
- **插上网线时接入点消失** — 这是「关闭 Wi-Fi」选项的作用。请关闭它或拔掉网线。
- **看不到接入点** — 等最多两分钟，检查模式和「关闭 Wi-Fi」选项。如果无效 — 请重启设备。
