# 管理员指南

本页面向维护设备的人员：SSH 访问、访问恢复、服务与日志管理。日常使用设备时不需要它。

## 通过 SSH 访问

连接到设备的网络（接入点或共用网络）并执行：

```
ssh malina@<设备地址>
```

- 在接入点网络中，地址为 `10.10.100.254`。
- 在共用网络中，为设备通过 DHCP 获得或手动设置的地址。

默认密码为 `malina-26`。它同样适用于用户 `root`。

密码在「系统参数 → 修改密码」页面修改，并立即同时作用于网页登录和 SSH。

## 如果密码丢失

- 如果 SSH 访问仍可用，请登录并通过网页页面「系统参数」修改密码。
- 如果网页密码和 SSH 密码都丢失，没有重新安装设备之外的标准办法来恢复访问。请联系设备负责人。

## 服务管理

打开「系统 → 服务」。

- **«Малина»** 标签页 — 子系统服务。可以启动和停止。
- **「系统」** 标签页 — 操作系统服务，仅可查看。

停止前请先阅读服务行中的注释。有些服务不能停：

- 网络服务 — 会失去对管理后台的访问和接入点；
- 网页管理后台本身 — 界面会关闭；
- 关键的系统服务 — 可能破坏设备运行；
- 定时器和由自动化管理的服务，无需手动启动。

如果停止网络服务后失去访问，请重启设备。

## 重启与关机

- 「系统参数 → 电源管理」— 重启和正常关机。
- 「服务 → 重启 Malina」— 同一操作。

重启后会出现等待页面。它会检查可用性，最长两分钟。如果更久 — 请手动刷新页面。

关闭设备时，请等到完全停止后再断开电源。

## 网络：模式与访问恢复

- **模式 1「接入点」** — 设备自行创建 Wi-Fi 网络。管理后台可在该网络中的设备地址（默认 `10.10.100.254`）访问。有线端口接入共用网络。
- **模式 2「Wi-Fi 客户端」** — 设备接入外部 Wi-Fi 网络。管理后台可在设备在该网络中获得的地此访问。供有线客户端使用的本地网络保留在 `eth0` 上。

切换模式后访问地址会改变。如果保存后失去访问，请按路由器中的新地址寻找设备。如果无法接入外部网络，设备会临时自行开启接入点。

如果在有线网段上检测到外来的 DHCP 服务器，设备会暂停自己的地址分配，但仍可通过自己的地址访问。当外来服务器消失后，分配会自动恢复。

## 日志

「系统 → 系统信息 → 日志」— 查看系统日志。文件列表是固定的，日志只读。

若要将日志转发到外部服务器，请在「系统参数 → 日志」中填写地址。如果字段为空，则使用来自网络设置的地址。

## 时间

- 设备时区在「系统参数 → 主机」中修改。
- MAP 时间每 10 分钟与设备同步一次，如果偏差超过一分钟。可在同一处「MAP 时间同步」中关闭。

## 监控

「系统参数 → 监控」启用周期性向外部接收方发送通知。需要填写接收方 IP 和周期。如果不需要监控，请保持关闭。

## API

- [Native API：lists, raws](api-native.md) — 令牌、列表、原始数据、写入与统计。
- [Legacy API](api-legacy.md) — 全部旧 API 以及与「主节点」的兼容性。
- Native API 使用 Bearer 令牌或 cookie。Legacy 读取无需鉴权即可访问，Legacy 写入使用 HTTP Basic（`malina` + 密码）。

## 故障时怎么办

1. 打开「系统信息」：检查温度、电源、磁盘和故障服务。
2. 打开「服务」：查看服务状态。
3. 打开「日志」：查找错误消息。
4. 如果设备卡死 — 请重启它。
5. 如果问题反复出现 — 保存描述和时间，联系开发者。
