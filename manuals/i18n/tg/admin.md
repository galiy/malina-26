# Дастури маъмур

Ин саҳифа — барои касе, ки дастгоҳро хидматрасонӣ мекунад: дастрасӣ тавассути
SSH, барқарорсозии дастрасӣ, идоракунии хизматҳо ва журналҳо. Барои корҳои
муқаррарӣ бо дастгоҳҳо он зарур нест.

## Дастрасӣ тавассути SSH

Ба шабакаи дастгоҳ пайваст шавед (нуқтаи дастрасӣ ё шабакаи умумӣ) ва иҷро кунед:

```
ssh malina@<суроғаи-дастгоҳ>
```

- Дар шабакаи нуқтаи дастрасӣ суроға — `10.10.100.254`.
- Дар шабакаи умумӣ — суроғае, ки дастгоҳ тавассути DHCP ё дастӣ гирифтааст.

Дар ҳолати пешфарз рамз — `malina-26`. Он ҳамчунин барои корбари `root` амал
мекунад.

Рамз дар саҳифаи «Параметрҳои система → Тағйири рамз» иваз мешавад ва дарҳол
барои воридшавӣ тавассути веб ва SSH амал мекунад.

## Агар рамз гум шуда бошад

- Агар дастрасӣ тавассути SSH боқӣ монда бошад, ворид шавед ва рамзро тавассути
  саҳифаи веби «Параметрҳои система» иваз кунед.
- Агар ҳам рамзи веб ва ҳам рамзи SSH гум шуда бошанд, роҳи штатии барқарорсозии
  дастрасӣ бе аз нав насб кардани дастгоҳ вуҷуд надорад. Ба касе, ки барои дастгоҳ
  масъул аст, муроҷиат кунед.

## Идоракунии хизматҳо

«Система → Хизматҳо»-ро кушоед.

- Ҷадвали **«Малина»** — хизматҳои зерсистема. Онҳоро оғоз ва бас кардан мумкин
  аст.
- Ҷадвали **«Системавӣ»** — хизматҳои системаи оператсионӣ, танҳо тамошо.

Пеш аз бас кардан шарҳи сатри хизматро хонед. Баъзе хизматҳоро бас кардан мумкин
нест:

- хизмати шабака — дастрасӣ ба панел ва нуқтаи дастрасӣ ғайб мезанад;
- худи панели веб — интерфейс пӯшида мешавад;
- хизматҳои муҳими ОС — метавонанд кори дастгоҳро вайрон кунанд;
- таймерҳо ва хизматҳое, ки бо автоматика идора мешаванд, дастӣ оғоз кардан лозим
  нест.

Агар пас аз бас кардани хизмати шабака дастрасӣ ғайб завад, дастгоҳро аз нав оғоз
кунед.

## Аз нав оғоз ва хомӯш кардан

- «Параметрҳои система → Идоракунии барқ» — аз нав оғоз ва хомӯшкунии дуруст.
- «Хизматҳо → Аз нав оғоз кардани малина» — ҳамон кор.

Пас аз аз нав оғоз саҳифаи интизорӣ кушода мешавад. Он то ду дақиқа дастрасиро
санҷида меистад. Агар бештар — саҳифаро дастӣ навсозӣ кунед.

Ҳангоми хомӯшкунӣ то пурра бас шудани кор интизор шавед ва танҳо пас аз он барқро
канед.

## Шабака: ҳолатҳо ва барқарорсозии дастрасӣ

- **Ҳолати 1 «Нуқтаи дастрасӣ»** — дастгоҳ шабакаи Wi-Fi-ро месозад. Панел аз рӯи
  суроғаи дастгоҳ дар ин шабака дастрас аст (`10.10.100.254` дар ҳолати пешфарз).
  Порти симӣ ба шабакаи умумӣ пайваст мешавад.
- **Ҳолати 2 «Мизоҷи Wi-Fi»** — дастгоҳ ба шабакаи Wi-Fi-и беруна пайваст мешавад.
  Панел аз рӯи суроғае, ки дастгоҳ дар ин шабака гирифтааст, дастрас аст. Шабакаи
  маҳаллӣ барои мизоҷони симӣ дар `eth0` боқӣ мемонад.

Ҳангоми иваз кардани ҳолат суроғаи дастрасӣ иваз мешавад. Агар пас аз нигоҳ доштан
дастрасӣ ғайб завад, дастгоҳро аз рӯи суроғаи нав дар роутер ҷустуҷӯ кунед. Агар
пайвастшавӣ ба шабакаи беруна муяссар нашуд, дастгоҳ худаш муваққатан нуқтаи
дастрасиро мебардорад.

Агар дар сегменти симӣ сервери DHCP-и бегона ошкоро шавад, дастгоҳ тақсими
суроғаҳои худро бозмедорад, вале аз рӯи суроғаи худ дастрас боқӣ мемонад. Вақте
ки сервери бегона ғайб мезанад, тақсимот худкор барқарор мешавад.

## Журналҳо

«Система → Маълумот дар бораи система → Журналҳо» — тамошои журналҳои система.
Рӯйхати файлҳо собит аст, журналҳо танҳо барои хониш дастрасанд.

Барои фиристодани журналҳо ба сервери беруна суроғаро дар «Параметрҳои система →
Журналгирӣ» нишон диҳед. Агар майдон холӣ бошад, суроға аз танзимоти шабака
истифода мешавад.

## Вақт

- Минтақаи вақти дастгоҳ дар «Параметрҳои система → Хост» иваз мешавад.
- Вақти МАП ҳар 10 дақиқа бо дастгоҳ ҳамоҳанг карда мешавад, агар ихтилоф бештар аз
  як дақиқа бошад. Дар ҳамон ҷо, дар «Ҳамоҳангсозии вақти МАП» хомӯш карда
  мешавад.

## Мониторинг

«Параметрҳои система → Мониторинг» фиристодани даврии огоҳиномаҳоро ба қабулкунандаи
беруна фаъол мекунад. IP-и қабулкунанда ва давраро нишон додан лозим аст. Агар
мониторинг лозим набошад, онро хомӯш монед.

## API

- [Native API: lists, raws](api-native.md) — токенҳо, рӯйхатҳо, контрактҳои хом,
  навиштан ва омор.
- [Legacy API](api-legacy.md) — тамоми API-и кӯҳна ва ҳамоҳангӣ бо «Гиреҳи Мастер».
- Native-API токени Bearer ё cookie-ро истифода мебарад. Legacy-хониш бе
  авторизатсия кушода аст, legacy-навиштан — HTTP Basic (`malina` + рамз).

## Чӣ бояд кард ҳангоми носозиҳо

1. «Маълумот дар бораи система»-ро кушоед: ҳарорат, барқ, дискҳо ва хизматҳои
   носозро санҷед.
2. «Хизматҳо»-ро кушоед: ҳолати хизматҳоро бубинед.
3. «Журналҳо»-ро кушоед: паёми хатогиҳоро ёбед.
4. Агар дастгоҳ «якноқ» шуда бошад — онро аз нав оғоз кунед.
5. Агар мушкил такрор шавад — тавсиф ва вақтро сабт кунед, ба таҳиягар муроҷиат
   кунед.
