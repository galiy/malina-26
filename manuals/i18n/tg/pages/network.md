# Танзими шабака

![Танзими шабака: ҳолатҳо ва параметрҳо](../img/network/screen.png)

## Кай ба ин ҷо

- Лозим аст интихоб кунед, ки дастгоҳ дар шабака чӣ тавр кор мекунад: шабакаи
  Wi-Fi-и худро месозад ё ба мавҷуда пайваст мешавад.
- Лозим аст ном ё рамзи нуқтаи дастрасӣ иваз карда шавад.
- Лозим аст, ки мизоҷони нуқтаи дастрасӣ ба интернет бароянд.
- Лозим аст суроғаҳо иваз карда шаванд ё тақсими DHCP дар порти симӣ хомӯш карда
  шавад.

## Ду ҳолат

Дастгоҳ дар яке аз ду ҳолат кор мекунад. Гузариш — интихоби ҷадвал ва «Нигоҳ доштан».
Ҳар ду маҷмӯи танзимот алоҳида нигоҳ дошта мешаванд ва ҳангоми гузариш гум
намешаванд.

### Нуқтаи дастрасӣ

Дастгоҳ шабакаи Wi-Fi-ро месозад, суроғаҳоро тақсим мекунад ва метавонад
мизоҷонро тавассути порти симӣ ба интернет баровард.

Майдонҳо:

- **SSID** — номи шабака.
- **Рамз** — рамзи WPA2, ҳадди аққал 8 аломат.
- **Канал** — `auto` ё 1–11.
- **Кишвар** — минтақа барои Wi-Fi.
- **Хомӯш кардани Wi-Fi** — нуқтаи дастрасиро хомӯш кардан, то даме Ethernet пайваст
  аст, ва пас аз ҷудо кардани кабел аз нав бардоштан.
- **Шабакаи мо / DHCP** — суроғаи IP-и дастгоҳ, маска, оғоз ва анҷоми ҳавзи
  суроғаҳо барои мизоҷон.
- **Ethernet** — `DHCP` ё `static`; барои ҳолати статикӣ — IP, маска, шлюз,
  DNS.
- **Транзити интернет (NAT)** — иҷозат додани баромади мизоҷон ба интернет тавассути
  Ethernet. Дар ҳолати пешфарз фаъол.
- **Captive-portal** — пешниҳод кардани саҳифаи воридшавӣ ба мизоҷон ҳангоми
  пайвастшавӣ. Дар ҳолати пешфарз фаъол.

### Мизоҷи Wi-Fi

Дастгоҳ ба шабакаи Wi-Fi-и беруна пайваст мешавад, ва порти симӣ ба шабакаи маҳаллӣ
барои мизоҷон табдил меёбад.

Майдонҳо:

- **SSID** ва **Сканер кардан** — шабакаи берунаро интихоб кардан.
- **Рамз** шабакаи беруна.
- **IP STA** — `DHCP` ё `static`; барои ҳолати статикӣ — IP, маска, шлюз, DNS.
- **Шабакаи мо / DHCP (eth0)** — суроғаи IP-и дастгоҳ, маска, ҳавзи суроғаҳо.
- **Тақсим кардани DHCP дар eth0** — додани суроғаҳо ба мизоҷони симӣ ё не. Дар
  ҳолати пешфарз фаъол.

## Чӣ тавр ҳолатро иваз кардан

1. «Система → Танзими шабака»-ро кушоед.
2. Ҷадвали ҳолати лозимро интихоб кунед.
3. Майдонҳоро пур кунед.
4. «Нигоҳ доштан»-ро пахш кунед.

Шабака аз нав оғоз мешавад ва пайвасти ҷорӣ метавонад канда шавад. Пас аз нигоҳ
доштан аз нав пайваст шавед:

- дар ҳолати нуқтаи дастрасӣ — ба Wi-Fi-и дастгоҳ, суроғаи дастгоҳ дар ҳолати пешфарз
  `10.10.100.254`;
- дар ҳолати мизоҷ — ба шабакаи Wi-Fi-и беруна ва суроғаи нави дастгоҳро дар
  рӯйхати мизоҷони роутер ёбед.

Тугмаи «Барқарор кардан» майдонҳоро ба қиматҳои охирин нигоҳдошташуда бармегардонад,
на ба заводӣ.

## Чӣ тавр рамзи нуқтаи дастрасиро иваз кардан

1. Ҷадвали «Нуқтаи дастрасӣ»-ро кушоед.
2. Рамзро иваз кунед (ҳадди аққал 8 аломат).
3. Нигоҳ доред ва аз нав ба шабака пайваст шавед.

## Чӣ тавр санҷид

- «Маълумот дар бораи система → Ҳолати шабака» ҳолати доимӣ ва ҷориро нишон медиҳад.
- Мизоҷон суроғаҳоро мегиранд, агар тақсим фаъол бошад.
- Ҳангоми NAT фаъол мизоҷони нуқтаи дастрасӣ тавассути Ethernet ба интернет мебароянд.

## Агар нашавад

- **Пас аз нигоҳ доштан дастрасӣ ғайб зад** — суроға ё ҳолат иваз шуд. Дастгоҳро
  аз рӯи суроғаи нав ёбед ё ба нуқтаи дастрасӣ пайваст шавед.
- **Ба Wi-Fi-и беруна пайваст намешавад** — SSID, рамз ва масофаи шабакаро санҷед.
  Пас аз нокомӣ дастгоҳ худаш нуқтаи дастрасиро мебардорад, то шумо танзимотро
  ислоҳ кунед.
- **Мизоҷони нуқтаи дастрасӣ интернет надоранд** — Ethernet-и пайваст бо интернет
  ва NAT-и фаъол лозим аст.
- **Мизоҷони симӣ суроға намегиранд** — «Тақсим кардани DHCP дар eth0»-ро ва
  ҳолати «Монитори DHCP»-ро дар «Маълумот» санҷед. Ҳангоми ошкор шудани DHCP-и
  бегона тақсим қасдан боздошта мешавад.
- **Нуқтаи дастрасӣ ҳангоми пайваст кардани кабел ғайб зад** — опсияи «Хомӯш
  кардани Wi-Fi» ҳамин тавр кор мекунад. Онро хомӯш кунед ё кабелро канед.
- **Нуқтаи дастрасӣ намоён нест** — то ду дақиқа интизор шавед, ҳолат ва опсияи
  «Хомӯш кардани Wi-Fi»-ро санҷед. Агар ёрӣ накунад — дастгоҳро аз нав оғоз кунед.
