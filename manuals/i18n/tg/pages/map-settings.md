# Танзими МАП

![Танзими МАП: ҳолат ва форма](../img/map-settings/screen.png)

## Кай ба ин ҷо

- МАП намоиш дода намешавад ё маълумот навсозӣ намешавад — санҷидан лозим аст, ки
  пурсиш фаъол аст ё не.
- Лозим аст пурсиши МАП муваққатан хомӯш карда шавад.
- Лозим аст муфассалии журнал барои ташхис боло бардошта шавад.

## Чӣ мебинед

Дар боло — корти «Ҳолати дастгоҳҳо»: ҳамаи МАП-ҳое, ки дастгоҳ мебинад. Барои
ҳар кадом муайянкунанда, рақами сериявӣ, порт, модел, протокол, суръат,
ҳолат ва вақти пурсиши муваффақи охирин нишон дода мешавад. Ҳолати «OK» маънои он
дорад, ки маълумот ба наздикӣ омада буд; «Пайваст нест» — ки дастгоҳ хомӯш аст.
Корт ҳар як сония навсозӣ мешавад.

Дар поён — формаи танзим.

## Чӣ тавр пурсишро фаъол ё хомӯш кардан

1. «Фаъол»-ро қайд кунед ё қайдро бардоред.
2. «Нигоҳ доштан»-ро пахш кунед.

Вақте пурсиш хомӯш аст, хизмат ба кори худ идома медиҳад, вале МАП пурсида
намешавад: маълумоти нав намеояд, дар корти ҳолат ҳолати охирин боқӣ мемонад.

## Чӣ тавр сатҳи журналро иваз кардан

Сатҳро интихоб кунед ва нигоҳ доред:

- **Ислоҳ** — муфассалтарин, барои ташхис.
- **Маълумот** — ҳолати муқаррарӣ.
- **Огоҳӣ** — танҳо огоҳиномаҳо.
- **Хато** — танҳо хатогиҳо.

Дар ҳолати пешфарз «Маълумот» истифода мешавад. Сатҳи муфассалро муваққатан фаъол
кардан лозим: он журналро зудтар пур мекунад.

## Чӣ тавр санҷед, ки ҷорӣ шуд

- Пас аз нигоҳ доштан паёми муваффақият пайдо мешавад.
- Танзимот дарҳол, бе аз нав оғоз кардани хизмат ҷорӣ мешаванд.
- Дар корти ҳолат ҳолати МАП бояд «OK» боқӣ монад, ва вақти муваффақияти охирин —
  навсозӣ шавад.

## Агар нашавад

- **Пас аз нигоҳ доштан пурсиш иваз нашуд** — нигоҳ доштро такрор кунед. Агар
  ёрӣ накунад, ҳолати хизматро дар саҳифаи «Хизматҳо» санҷед.
- **Дар корт «Маълумот нест / пурсиш хомӯш»** — пурсишро фаъол кунед ва нигоҳ доред.
- **МАП дар ҳолати «Пайваст нест»** — кабел, барқ ва портро санҷед; дар сурати
  зарурат ба маъмур муроҷиат кунед.
- **«Сатҳи нодурусти журналгирӣ»** — қиматро аз рӯйхат интихоб кунед.
