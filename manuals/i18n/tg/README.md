# Роҳнамои корбар «Малина»

«Малина» — дастгоҳ барои назорат ва идоракунии таҷҳизоти энергетикӣ: МАП, КЭС,
батареяҳои аккумуляторӣ бо BMS ва инверторҳои шабакавӣ. Идоракунӣ — тавассути
панели веб, ки аз телефон, планшет ё компютер тавассути шабака дастрас аст.

Ҳуҷҷатгузорӣ аз рӯи саҳифаҳои меню сохта шудааст. Агар намедонед, аз куҷо сар
кунед, қисми «Аз куҷо сар кардан»-ро кушоед.

![Саҳифаи асосӣ: кортҳои дастгоҳҳои пайвастшуда](img/main/home.png)
