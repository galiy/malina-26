# Руководство пользователя ПАК «Микроарт-Малина»

«Микроарт-Малина» — устройство (Raspberry Pi) с веб-админкой: показывает состояние
системы, умеет работать точкой доступа Wi-Fi и клиентом Wi-Fi, раздавать интернет,
управлять службами и показывать журналы.

## Быстрый старт

1. Подключитесь к устройству:
   - **точка доступа Wi-Fi**: сеть **`Malina`**, пароль **`malina-26`**
     (адрес устройства в этой сети — `10.10.100.254`);
   - либо по общей сети/кабелю — по адресу, который устройство получило на `eth0`.
2. Откройте веб-админку: `http://<адрес-устройства>/`.
3. Войдите: пользователь **`malina`**, пароль **`malina-26`**.

## Доступы по умолчанию

| Доступ | Логин | Пароль |
|---|---|---|
| Веб-админка | `malina` | `malina-26` |
| SSH | `malina` | `malina-26` |
| SSH (root) | `root` | `malina-26` |
| Wi-Fi (точка доступа) | SSID `Malina` | `malina-26` |

> Рекомендуется сменить пароль пользователя (страница «Параметры системы») и
> пароль точки доступа (страница «Настройка сети» → «Режим 1»).
