# Запись образа на SD-карту

Инструкция для установки «Малины» на Raspberry Pi 3. Образ — полный образ диска
(загрузочный раздел, система и `/malina`). Запись стирает карту полностью.

## Что понадобится

- SD-карта **8 ГБ или больше** (образ занимает ~6,5 ГиБ; нужна реальная ёмкость
  не меньше 7 ГиБ).
- Картридер.
- Компьютер с Windows 10/11 или Linux.
- Блок питания Raspberry Pi 3: 5 В, не меньше 2,5 А.
- Скачанный архив образа, например `malina-<версия>-rpi3-8gb.img.zip`.

Проверьте, что карта не нужна для других целей: все данные на ней будут удалены.

## Шаг 1. Скачать и проверить архив

Скачайте архив и файл с контрольной суммой с одной страницы релиза.

**Windows (PowerShell или cmd):**

```bat
certutil -hashfile malina-<версия>-rpi3-8gb.img.zip SHA256
```

**Linux:**

```bash
sha256sum malina-<версия>-rpi3-8gb.img.zip
```

Сравните результат с опубликованным SHA256. Если не совпадает — архив
повреждён, скачайте заново.

> Архив большой (несколько гигабайт) и содержит ZIP64. Windows 10/11 открывает
> его Проводником. Старые архиваторы могут не поддерживать ZIP64.

## Шаг 2. Выбрать способ записи

| Программа | Платформа | Нужно распаковывать ZIP | Когда выбрать |
|---|---|---|---|
| **Raspberry Pi Imager** | Windows, Linux, macOS | Нет | Самый простой вариант |
| **balenaEtcher** | Windows, Linux, macOS | Нет | Привычный интерфейс, есть проверка |
| **Rufus** | Windows | Да, нужен `.img` | Если уже пользуетесь Rufus |
| **Win32DiskImager** | Windows | Да, нужен `.img` | Старый проверенный вариант |
| **dd** | Linux | Да, нужен `.img` | Без лишних программ |

Если программа умеет открыть `.zip` — не распаковывайте архив. Если нет —
распакуйте его и работайте с файлом `.img`.

## Windows: Raspberry Pi Imager

1. Установите Raspberry Pi Imager с официального сайта.
2. Вставьте SD-карту.
3. Нажмите **Choose OS** → прокрутите вниз → **Use custom**.
4. Выберите скачанный `.zip` (распаковывать не нужно).
5. Нажмите **Choose Storage** и выберите SD-карту.
6. Нажмите **Write** и подтвердите.
7. Дождитесь окончания записи и проверки.
8. Закройте программу и извлеките карту.

Не включайте в Imager дополнительные настройки (hostname, Wi-Fi, пользователь):
образ уже настроен, лишние параметры могут конфликтовать с первым запуском.

## Windows: balenaEtcher

1. Установите balenaEtcher.
2. Нажмите **Flash from file** и выберите `.zip` или `.img`.
3. Нажмите **Select target** и выберите SD-карту.
4. Нажмите **Flash!** и подтвердите.
5. Дождитесь записи и проверки (Validate).
6. Извлеките карту.

Если Etcher показывает несколько дисков — проверьте, что выбран именно картридер,
а не системный диск.

## Windows: Rufus

Rufus не открывает ZIP, поэтому сначала распакуйте архив:

1. Щёлкните по `.zip` правой кнопкой → **Извлечь все**.
2. Получите файл `.img`.
3. Запустите Rufus.
4. В **Устройство** выберите SD-карту.
5. Нажмите **Выбрать** и укажите `.img`.
6. Если Rufus спросит про режим записи — выберите **DD-образ** (не ISO).
7. Нажмите **Старт** и подтвердите стирание.
8. Дождитесь завершения и извлеките карту.

Не меняйте схему разделов и файловую систему: образ уже содержит нужную
разметку.

## Windows: Win32DiskImager

1. Распакуйте `.zip` и получите `.img`.
2. Запустите Win32DiskImager от имени администратора.
3. В поле образа выберите `.img`.
4. В списке устройств выберите букву SD-карты.
5. Нажмите **Write** и подтвердите.
6. Дождитесь завершения, закройте программу, извлеките карту.

Win32DiskImager показывает буквы дисков, а не физические устройства. Убедитесь,
что выбрана именно карта.

## Linux: Raspberry Pi Imager или balenaEtcher

Работает так же, как в Windows: выберите `.zip`/`.img` и SD-карту, запишите.
Программы требуют прав администратора.

## Linux: `dd`

Сначала распакуйте архив и определите устройство карты.

```bash
unzip malina-<версия>-rpi3-8gb.img.zip
lsblk
```

В `lsblk` найдите карту по размеру и модели. Это будет что-то вроде `/dev/sdb`
(не `/dev/sdb1` — нужен диск целиком, без номера раздела).

```bash
sudo umount /dev/sdb1 2>/dev/null || true
sudo dd if=malina-<версия>-rpi3-8gb.img of=/dev/sdb bs=4M status=progress conv=fsync
sync
```

Проверьте имя устройства **до** нажатия Enter: `dd` не спрашивает подтверждения и
уничтожает всё на выбранном диске.

## Шаг 3. Первый запуск

1. Вставьте карту в Raspberry Pi 3.
2. Подключите питание.
3. Подождите около минуты, максимум две.
4. На телефоне или ноутбуке подключитесь к Wi-Fi **Malina**, пароль
   **malina-26**.
5. Откройте `http://10.10.100.254/` или согласитесь на предложение «Войти в
   сеть».
6. Войдите паролем **malina-26** и сразу смените пароли.

Подробнее — «С чего начать» в руководстве пользователя.

## Если что-то пошло не так

- **Windows предлагает отформатировать карту.** Откажитесь. После записи Windows
  не видит Linux-разделы — это нормально.
- **Карта не видна в программе.** Проверьте картридер и порт USB, перезапустите
  программу. В Rufus включите отображение USB-устройств, но будьте осторожны:
  можно выбрать системный диск.
- **Ошибка записи на 99%.** Часто это плохой картридер или карта. Попробуйте
  другой картридер/карту.
- **Rufus пишет про ISO/DD.** Выберите DD.
- **После записи устройство не загружается.** Проверьте блок питания (5 В, ≥2,5 А)
  и карту. Попробуйте записать заново другой программой.
- **Wi-Fi `Malina` не появился.** Подождите до двух минут, проверьте питание.
  Если не помогает — перезапишите карту.
- **Карта «8 ГБ», но образ не помещается.** Реальная ёмкость китайских карт часто
  меньше номинала. Нужна карта с фактической ёмкостью не менее 7 ГиБ; подойдёт
  карта 16 ГБ.
- **Хэш не совпадает.** Архив скачан не полностью или повреждён. Скачайте заново,
  желательно другим браузером.
