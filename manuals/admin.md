# Инструкция администратора

Эта страница — для того, кто обслуживает устройство: доступ по SSH, восстановление
доступа, управление службами и журналами. Для обычной работы с устройствами она не
нужна.

## Доступ по SSH

Подключитесь к сети устройства (точка доступа или общая сеть) и выполните:

```
ssh malina@<адрес-устройства>
```

- В сети точки доступа адрес — `10.10.100.254`.
- В общей сети — адрес, который устройство получило по DHCP или заданный вручную.

По умолчанию пароль — `malina-26`. Он же действует для пользователя `root`.

Пароль меняется на странице «Параметры системы → Смена пароля» и сразу действует
для веб-входа и SSH.

## Если пароль утрачен

- Если доступ по SSH сохранился, войдите и смените пароль через веб-страницу
  «Параметры системы».
- Если утрачены и веб-пароль, и пароль SSH, штатного способа восстановить доступ
  без переустановки устройства нет. Обратитесь к тому, кто отвечает за устройство.

## Управление службами

Откройте «Система → Сервисы».

- Вкладка **«Малина»** — службы подсистемы. Их можно запускать и останавливать.
- Вкладка **«Системные»** — службы операционной системы, только просмотр.

Перед остановкой прочитайте комментарий в строке службы. Некоторые службы
останавливать нельзя:

- служба сети — пропадёт доступ к админке и точка доступа;
- сама веб-админка — интерфейс закроется;
- критичные службы ОС — могут нарушить работу устройства;
- таймеры и службы, управляемые автоматикой, вручную запускать не нужно.

Если доступ потерян после остановки сетевой службы, перезагрузите устройство.

## Перезагрузка и выключение

- «Параметры системы → Управление питанием» — перезагрузка и корректное выключение.
- «Сервисы → Перезагрузить малину» — то же самое.

После перезагрузки откроется страница ожидания. Она проверяет доступность до двух
минут. Если дольше — обновите страницу вручную.

При выключении дождитесь полной остановки и только потом отключайте питание.

## Сеть: режимы и восстановление доступа

- **Режим 1 «Точка доступа»** — устройство создаёт Wi-Fi-сеть. Админка доступна по
  адресу устройства в этой сети (`10.10.100.254` по умолчанию). Проводной порт
  подключается к общей сети.
- **Режим 2 «Wi-Fi клиент»** — устройство подключается к внешней Wi-Fi-сети. Админка
  доступна по адресу, который устройство получило в этой сети. Локальная сеть для
  проводных клиентов остаётся на `eth0`.

При смене режима адрес доступа меняется. Если после сохранения доступ пропал,
ищите устройство по новому адресу в роутере. Если подключиться к внешней сети не
удалось, устройство само временно поднимает точку доступа.

Если на проводном сегменте обнаружен чужой DHCP-сервер, устройство приостанавливает
свою раздачу адресов, но остаётся доступным по своему адресу. Когда чужой сервер
исчезает, раздача возобновляется автоматически.

## Журналы

«Система → Информация о системе → Логи» — просмотр системных журналов. Список
файлов фиксирован, журналы доступны только для чтения.

Для пересылки журналов на внешний сервер укажите адрес в «Параметры системы →
Логирование». Если поле пустое, используется адрес из настроек сети.

## Время

- Часовой пояс устройства меняется в «Параметры системы → Хост».
- Время МАП синхронизируется с устройством каждые 10 минут, если расхождение
  больше минуты. Отключается там же, в «Синхронизации времени МАП».

## Мониторинг

«Параметры системы → Мониторинг» включает периодическую отправку уведомлений на
внешний приёмник. Нужно указать IP приёмника и период. Если мониторинг не нужен,
оставьте его выключенным.

## API

- [Native API: lists, raws](api-native.md) — токены, списки, сырые контракты,
  запись и статистика.
- [Legacy API](api-legacy.md) — весь старый API и совместимость с «Мастер-Узлом».
- Native-API использует Bearer-токен или cookie. Legacy-чтение открыто без
  авторизации, legacy-запись — HTTP Basic (`malina` + пароль).

## Что делать при сбоях

1. Откройте «Информация о системе»: проверьте температуру, питание, диски и
   сбойные службы.
2. Откройте «Сервисы»: посмотрите состояние служб.
3. Откройте «Логи»: найдите сообщения об ошибках.
4. Если устройство зависло — перезагрузите его.
5. Если проблема повторяется — сохраните описание и время, обратитесь к
   разработчику.
