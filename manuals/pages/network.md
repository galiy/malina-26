# Настройка сети «Микроарт-Малина»

Документ описывает всю функциональность сетевой подсистемы ПАК: режимы, параметры
на странице «Настройка сети», служебные файлы и поведение (защита от чужого DHCP,
фолбэк, наблюдаемость). Обзор UI и индекс страниц — [ui.md](../ui.md).

![Настройка сети](../img/network.png)

## 1. Два режима работы

Устройство работает в одном из двух режимов (переключатель над полями; у активной
вкладки зелёный ✓, у неактивной — красный ⛔). Переключение — выбор вкладки и
**«Сохранить»** (сохранить и применить = перезапуск сети).

### Режим 1 — «Точка доступа» (mode1)
- `wlan0` работает **точкой доступа** (hostapd): SSID, пароль, канал, страна.
- **Наша сеть** (DHCP-сервер, dnsmasq) поднимается **на `wlan0`**:
  IP шлюза/сервера, маска, диапазон аренды.
- `eth0` — выход в общую сеть: **DHCP** или **статический** IP (маска, шлюз, DNS).
- **NAT**: клиенты точки доступа выходят в интернет через `eth0` (masquerade).
- **Captive portal**: перехват «каптивных» доменов и редирект на страницу портала.

### Режим 2 — «Wi-Fi клиент» (mode2)
- `wlan0` работает **клиентом** (wpa_supplicant): подключается к внешней точке
  (SSID/пароль), получает адрес по DHCP или статически (IP/маска/шлюз/DNS).
- `eth0` **всегда переводится в нашу сеть** (dnsmasq на `eth0`): IP сервера, маска,
  диапазон; при необходимости можно **выключить раздачу** DHCP (`Serve`).
- **NAT**: клиенты нашего сегмента на `eth0` выходят в интернет через `wlan0`.

## 2. Параметры на странице (`/network`)

Кнопки вверху: **«Восстановить»** (вернуть значения из сохранённого конфига) и
**«Сохранить»** (сохранить и применить). Поля подсвечиваются при ошибке.

### Общие (обе вкладки)
- **Режим** — `mode1` / `mode2`.

### Режим 1 (Точка доступа)
- **SSID** — имя точки доступа.
- **Password** — пароль WPA2 (минимум 8 символов для WPA2).
- **Channel** — `auto` или 1…11.
- **Country** — код страны (регуляторный домен).
- **Выключить Wi-Fi** — если включено, при **подключённом Ethernet** (`eth0` с
  линком) точка доступа и радио Wi-Fi гасятся, а при отключении кабеля — снова
  поднимаются. По умолчанию выключено (Wi-Fi работает всегда).
- **Наша сеть / DHCP (на wlan0)**: IP-адрес сервера (шлюз для клиентов), маска,
  `DHCP start`, `DHCP end`.
- **Ethernet (eth0)**: `DHCP` или `static`; для static — IP, маска, Gateway, DNS
  (DNS списком через запятую).
- **Internet transit (NAT)**: включить трансляцию (masquerade в `eth0`).
- **Captive portal**: включить перехват каптивных доменов.

### Режим 2 (Wi-Fi клиент)
- **SSID / Password** внешней точки (есть кнопка **Scan** — список сетей).
- **STA IP**: `DHCP` или `static`; для static — IP, маска, Gateway, DNS.
- **Наша сеть / DHCP (на eth0)**: IP сервера, маска, `DHCP start`, `DHCP end`.
- **Serve DHCP on eth0**: раздавать ли DHCP на нашем сегменте (см. защиту от чужого
  DHCP ниже).

### Валидация
Проверяются IPv4-адреса и маски, непротиворечивость диапазона DHCP (в пределах
подсети), допустимость значений SSID/пароля. Невалидные поля подсвечиваются, форма
не отправляется.

## 3. Подсистема `malina-netd`

Применением конфигурации и слежением за сетью управляет демон **`malina-netd`**
(`/malina/usr/local/sbin/malina-netd`). Он:
- применяет выбранный режим (`apply`), поднимает hostapd/dnsmasq/wpa/dhclient;
- настраивает NAT (`nft`), `ip_forward`, адресацию;
- ведёт монитор (чужой DHCP) и фолбэк;
- по таймеру выполняет `fallback-tick` (раз в минуту).

Команды (для диагностики по SSH):
```
/malina/usr/local/sbin/malina-netd status     # текущее состояние
/malina/usr/local/sbin/malina-netd apply      # применить конфиг
/malina/usr/local/sbin/malina-netd fallback-tick
```

### Файлы конфигурации (в `/malina`, rw)
- `/malina/etc/malina/network/mode1.json` — параметры режима 1.
- `/malina/etc/malina/network/mode2.json` — параметры режима 2.
- `/malina/etc/malina/network/active` — активный («постоянный») режим.
- `/malina/etc/malina/network/fallback.json` — пороги фолбэка (при наличии).

### Рабочие файлы (`/run/malina-net`, tmpfs)
- `hostapd.conf`, `dnsmasq.conf` — сгенерированные конфиги;
- `mode` — транзиентный override режима (для фолбэка);
- `monitor.state` — состояние монитора (`serving`, `foreign`, счётчик чистых проб);
- `dnsmasq.leases` — аренды клиентов точки доступа.

## 4. Защита от чужого DHCP (режим 2, `Serve`)

В нашем сегменте (`eth0`) может оказаться другой DHCP-сервер. Подсистема это
отслеживает:
- выполняется активный DHCP‑зонд; если обнаружен **чужой** сервер (иной server-id,
  не наш IP) — наша раздача **выключается**, конфигурация `eth0` **не меняется**;
- после двух подряд «чистых» проб раздача снова включается;
- монитор работает периодически; состояние видно на «Информации» в блоке
  «Состояние сети» (`Foreign DHCP`, `Clean probes`).

## 5. Фолбэк (режим 2 → режим 1)

В режиме 2, если нет STA-подключения **и** нет carrier на `eth0` дольше порога,
устройство **транзиентно** переключается в режим 1 (поднимает точку доступа), чтобы
остаться доступным. При появлении цели (STA-сеть видна) — **автоматический возврат**
в режим 2. Пороги задаются в `fallback.json` (`nolink_sec`, `scan_sec`), проверка —
таймером раз в минуту.

## 6. NAT и маршрутизация

- `ip_forward=1`; правила в `nft` таблице `ip malina` (masquerade в `eth0` для
  mode1 или в `wlan0` для mode2). Правила загружаются с полной заменой таблицы
  (без накопления дублей).

## 7. Наблюдаемость (журналирование)

- Встроенные журналы — на tmpfs (`/var/log`), плюс пересылка на удалённый
  **syslog-сервер**: адрес по умолчанию берётся из **DHCP (опция 7)**; можно задать
  вручную на странице «Параметры системы».
- В режиме 2 журнал раздачи DHCP/проб виден в `monitor.state` и в журналах юнитов.

## 8. Доступ к устройству

- В режиме 1: по адресу на `eth0` (в общей сети) и по `10.10.100.254` из сети AP.
- В режиме 2: по адресу, полученному `wlan0` (STA), — то есть по общей сети.
- Веб-админка: `http://<адрес>/` (логин `malina`, пароль по умолчанию `malina-26`).

## 9. Известные особенности (brcmfmac, Raspberry Pi)

- AP-режим на встроенном Wi-Fi (brcmfmac) **периодически «залипает»** (перестаёт
  вещать beacon). Лечится перезапуском `hostapd`; предусмотрен watchdog в
  `malina-netd`, в тяжёлых случаях — перезагрузка устройства.
- Команды `iw dev wlan0 station dump` и `hostapd_cli all_sta` в AP-режиме могут
  **зависать** — поэтому список клиентов берётся из аренд dnsmasq, а «онлайн» — по
  ARP; сигнал/битрейт для клиентов AP недоступны.
- Канал точки доступа по умолчанию — **11** (уход от перегруженных каналов).

## 10. Типовые сценарии

- **Смена режима**: «Настройка сети» → выбрать вкладку (✓/⛔) → «Сохранить».
  Сеть перезапустится; доступ может кратко прерваться (в режиме 2 — переподключение
  админки по новому адресу).
- **Сменить пароль точки доступа**: вкладка «Режим 1» → поле Password → «Сохранить».
- **Отключить NAT**: снять «Internet transit (NAT)» → «Сохранить».
- **Клиент к внешней сети**: вкладка «Режим 2» → SSID/пароль (или Scan) → при
  необходимости static IP → «Сохранить».
