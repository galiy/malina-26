# Раздел «БМС»

Пункт меню **БМС** — постоянный (как **МАП** и **КЭС**). Внутри:
- **устройства BMS** — по ссылке на страницу каждого (вставлены перед «Настройкой»);
- **Настройка** — шлюзы BMS-Receiver (последним пунктом).

## Страница устройства (`/bms?id&gen`)

- Закладки **«Панель» / «Информация» / «Управление»** — заготовки («в разработке»).
- Ниже закладок — **Memo с данными устройства в формате JSON** (живые значения,
  обновление ~1 раз в секунду).

## Настройка (`/bms/settings`)

Настройка **IP-шлюзов** сбора статистики BMS (`bms-reader`).

- Таблица шлюзов: **Хост / IP**, **Порт**, **Режим** (`modbus` — MODBUS-TCP; `none` —
  MODBUS-RTU или нативный протокол BMS поверх TCP).
- **Добавить шлюз** — новая строка; **✕** — удалить строку.
- **Сохранить** — пишет `/malina/etc/malina/bms-reader.json` и подаёт демону
  `bms-reader` команду **reload** (без перезапуска).

COM-устройства (BMS на USB-serial) обнаруживаются автоматически и в настройке не
указываются.

### Рамка «BMS-Reader» (`/bms/settings`)

Настройка сервиса **BMS-Receiver** (сбор телеметрии BMS):

- **Включено** — включить/выключить опрос BMS (по умолчанию **выключено**). Пока
  выключено, сервис активен, но батареи не опрашиваются, а список устройств пуст.
- **Уровень логирования** — debug / info / warn / error (по умолчанию **info**;
  при поставке — **debug**).

**Сохранить** пишет `/malina/etc/malina/bms-reader.json` и подаёт демону
`bms-reader` команду **reload** — применяется без перезапуска сервиса.

### Рамка «БМС-Прокси» (`/bms/settings`)

Настройка сервиса **BMS-Proxy** — моста телеметрии к инвертору по последовательному
порту (RS485). Поля:

- **Включено** — включить/выключить прокси (по умолчанию **выключено**). Пока
  выключено, сервис не ищет порт и не отвечает инвертору.
- **Скорость порта** — 2400 / 9600 / 19200 / 57600 / 115200 / 230400 (по умолчанию
  **19200**).
- **Уровень логирования** — debug / info / warn / error (по умолчанию **info**;
  при поставке на устройство — **debug**).
- **Адресация инвертора** — как инвертор нумерует батареи: **`1–16`** (по
  умолчанию) или **`0–15`**. От этого зависит, на какую BMS из списка живых
  отвечает запрошенный номер.
- **UDP-слушатель (шлюз)** — необязательный второй слушатель, если инвертор
  подключён через прозрачный UDP↔RS485-шлюз. Включается **явным флажком
  «Включено»**; при этом укажите адрес прослушивания (например `0.0.0.0:502`) —
  демон ответит теми же данными BMS, что и на COM-порт. **По умолчанию выключено.**
  Шлюз должен пересылать UDP-датаграммы инкапсулированных RS485-запросов инвертора
  на этот адрес и порт.

**Сохранить** пишет `/malina/etc/malina/bms-proxy.json` и подаёт демону
`bms-proxy` команду **reload** — новый уровень логирования и настройки применяются
без перезапуска сервиса.

## Главная страница

Раздел **БМС** с плитками устройств (по аналогии с разделами МАП/КЭС): тип, режим,
SoC, напряжение/ток/мощность/температура сборки, статус online/offline; клик — переход
на страницу устройства.
