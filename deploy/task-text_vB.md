# Текст задачи для нового агента (Вариант B)

Готовая краткая формулировка для постановки задачи агенту. Конкретный
порядок, команды и проверки в задаче не дублируются: агент читает
`deploy/redeploy-plan.md`, `deploy/local/deploy-local.sh` и
`deploy/manifest.tsv` и разбирается сам.

**Обязательно:** методика Варианта B — это `deploy/redeploy-plan.md` **целиком**
(заливка `socat` raw TCP, приём через `/dev/tcp` с проверкой SHA в `/dev/shm`,
sysrq-ребут, bootstrap-сеть через `/etc/cron.d/vb-bootstrap`). Заменять её
самодельной заливкой (например, `dd` образа по SSH-потоку) запрещено; если файл
выглядит «общим порядком» без этих шагов — поднять методику из истории git.

```
Выполни деплой Варианта B по deploy/redeploy-plan.md.

Сначала прочитай AGENTS.md, deploy/redeploy-plan.md,
deploy/local/deploy-local.sh и deploy/manifest.tsv.

Все параметры (целевой хост, доступы, раздатчик, образ) запроси у меня,
оператора. Ничего не подставляй по умолчанию и не трогай другие хосты.

Методику заливки (socat raw TCP, приём через /dev/tcp с проверкой SHA,
sysrq-ребут, bootstrap cron-hook) не импровизируй — она целиком в
deploy/redeploy-plan.md. Разрушительные шаги — только после моего
явного подтверждения.

Работай по шагам, после каждого показывай проверку. При расхождении
или неясности — остановись и задай вопрос.
```
