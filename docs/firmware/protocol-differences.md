# Прошивка МАП: отличия Титанатор ↔ Доминатор

Короткая памятка по итогам съёмок 2026-10-29 (Титанатор) и 2026-11-03
(Доминатор). Подробности — в `titanator/readme.md`, `dominator/readme.md` и
`*/logs/*/analysis.md`.

| Параметр | Титанатор | Доминатор |
|---|---|---|
| Модель (`_DevOpt`) | 3 | 1 |
| ЦПУ | dsP33MU810 (по загрузчику) | PIC18F46K22 (по имени образа `46k22`) |
| Скорость монитора/меню | 19200 (`0x809C`) | 57600 (`0xC034`, фактически 57 279) |
| **Скорость прошивки** | **625000** (`wValue=0x8004, wIndex=1`, FT232R даёт 631 579) | **19200** (`0x809C`) |
| **Вход в режим прошивки** | **командой по линии**: `0x0000=A5` → `0x0091=55AA` → `0x0000=06` | **только вручную** (кнопки/питание); команды нет |
| Маяк бутлоадера | `Load\r\n` в RX | `Load\r\n` (перед ним в RX приходит `0x80`) |
| Handshake загрузчика (TX) | `lrunU` (`6C 72 75 6E 55`) | `lrunU` (то же) |
| Эхо handshake от МАП | `L9131yU` | `L=;19yU` |
| Заголовок образа | `mXP1v4_5&31#…` | `mXP11v30_0&19#…` |
| Подпись в заголовке | **31 байт** (62 hex) | **32 байта** (64 hex) |
| Экранирование в потоке | `0x4B→4B4D`, `0x55→4B4C`, `0x57→4B43`, `0x5A→4B4E` | **то же самое** |
| Терминатор | `0x55` | `0x55` |
| Кадровые вставки | нет (только экранирование) | нет (только экранирование) |
| Меню: открыть транзакцию | `0x0000 = A5` | `0x0000 = 03` |
| Меню: закрыть | `0x0000 = 06` | `0x0000 = 06` (блок), `0x0000 = 07` (одиночные записи) |
| Меню: служебная запись | — | `0x0403 = 00` после одиночных правок |
| Состав cfg меню | 64 ячейки: блок `0x100…0x1F8` + одиночные `0x0A…0xD7` | 32 ячейки: только блок `0x100…0x1F8` |

## Что одинаково

- Физика: USB FTDI FT232R, 8N1, побайтовое эхо MicroArt.
- Первый кадр после смены скорости устройство отклоняет `e 04`; нужен повтор
  (`docs/microart-protocol.md` §7).
- Рукопожатие загрузчика и байт-стаффинг 4 служебных значений.
- Конец передачи — одиночный `0x55`.

## Практические следствия

- Логи и инструменты (`docs/firmware/tools/`) общие: сниффер не зависит от
  модели, отличается только разбор.
- Для Доминатора нельзя применять команду входа Титанатора
  (`0x0091=55 AA`): переход — только вручную.
- Скорость прошивки нельзя закладывать заранее: она берётся из `SET_BAUD`
  служебного слоя дампа (625000 у Титанатора, 19200 у Доминатора).
