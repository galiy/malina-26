# Разбор этапа monitor-save-menu (монитор + сохранение настроек ЖКИ)

Источник: `usb.pcapng` (16.8 МБ), разбор `parse-stage.sh` (по отдельному
указанию оператора; общее правило — во время прошивки не парсить).

## Итог обмена

- Период: 18:02:55–18:04:18 MSK.
- TX 21 679 Б = RX 21 679 Б (побайтовое эхо), 33 982 события.
- 33 961 bulk-пакет, размеры 1–2 байта: обмен сугубо побайтовый, крупных
  блоков нет.
- Начало потока: `72 7F 00 00 0F 0A 6F 03 82 E3 00 32 …` — как в `monitor`.

## Пакетная операция сохранения

Непрерывная серия без пауз 301 мс: **18:03:15.329–18:03:16.455**
(1713 событий, 2032 Б суммарно (≈по 1016 Б в каждую сторону), 1.126 с).

Блок настроек читается повторно (сигнатура `0x100 = 10 00 02 01 00 00 00 00`
в RX встречается дважды):

| Смещение в RX | Время MSK | Что это |
|---|---|---|
| 286 | 18:03:08.409 | первичное чтение после открытия порта (для отображения) |
| 3431 | 18:03:15.443–15.985 | повторное чтение, из него собран cfg |

Остальные серии по 233 события / 298 Б каждые ~3 с — обычный опрос монитора,
к сохранению не относятся.

## Сохранённый файл

`map2gui/Titanator_bak_202610291803.cfg` (1711 Б):
- заголовок `MAP MENU`;
- строки `0x100 … 0x1F8` по 8 байт;
- одиночные ячейки `0x10`, `0x31`, `0x32` (новые в ПО 4.x).

Значения из этого файла затем использовались на этапе `restore-menu`.
