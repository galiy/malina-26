# Заметки по этапу flash (прошивка)

Данные с экрана загрузчика `MAP2Gui_ v10.0`, снято оператором в процессе прошивки
(сообщено 2026-10-29 ~19:03 MSK, прогресс 70%).

| Поле | Значение |
|---|---|
| Прогресс | 70% |
| Статус | «Загрузка Файла» |
| Ошибки | Нет ошибок |
| Имя файла | `map2gui/mXP1p1v4_5_Titanator_tst3.map2` |
| VerDevice | MAP SIN |
| VerPlatPic | 1 |
| VerPlatPow | 1.x |
| VerBoot | 9 |
| VerPO | 4.5 |
| CPU | **dsP33MU810** |

Важно: фактический ЦПУ — `dsP33MU810` (dsPIC33), а не PIC18F46K22, на который
ориентировался прошлый реверс (`disasm/map2gui/reverse-firmware-docs/`). Прошлая
попытка упиралась в несовпадение CPU; теперь `VerPO=4.5` соответствует образу
`mXP1p1v4_5_Titanator_tst3.map2` — прошивка идёт (70% на момент снимка).
