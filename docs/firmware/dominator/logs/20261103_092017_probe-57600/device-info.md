# Опрос Доминатора (только чтение, MicroArt)

- Время: 2026-11-03 ~09:20 MSK
- Порт: `/dev/ttyUSB0` (FTDI 0403:6001, bus 7 dev 11)
- Скорость: **57600 8N1**
- Запрос: `r`, page=15 (16 байт), адрес `0x0000`, побайтовое эхо
- Важно: первый кадр после смены скорости устройство отклоняет (`e 04`,
  ErrRS_cod); вторая попытка — валидный ответ. Совпадает с описанием в
  `docs/microart-protocol.md` §7.
