## Баги (исправлены)

1. **CSS `.home-title` определён дважды — заголовок страницы станет невидимым.**
   *Статус: исправлено.* Заголовок плитки скоуплен в `.home-tile .home-title`
   (`app.css`), у него сброшен `margin`. Страничный `<h1 class="home-title">`
   больше не перекрывается белым заголовком плитки.

2. **`tempFrom` не различает «нет поля» и `0`** (показывал −50 °C вместо ND).
   *Статус: исправлено.* Сигнатура изменена на `tempFrom(f map[string]uint32, key string)`,
   проверяется наличие ключа. Добавлена проверка в тест `TestMapTileFieldsND`
   (grid/batt/load `T` → `nd=true`).

3. **`mainValue.Raw` заполняется округлённым значением.**
   *Статус: исправлено.* `mv()` теперь принимает `(v, raw, color)`; `Raw` хранит
   исходное (без округления) значение. Ассерты добавлены в `TestMapTileFields`
   (`Grid.U.Raw == 230`, `Batt.U.Raw == 51.5`).

## Минор / ниты

4. `batInput.Charging` (`ocv.go`) в `socEstimated` не используется — знак тока уже
   применён вызывающими, поправка всегда вычитает `Current`.
   *Статус: оставлено.* Поле входит в контракт `batInput` (спека §5.3), задаётся
   обеими фасадами (МАП по режиму, КЭС `true`). В `socEstimated` направление
   берётся из знака `Current`, что корректно для обоих источников; `Charging`
   сохранено намеренно как документирующее поле контракта, а не ловушка.

5. `PNET_Sign_P`: Go `f["PNET_Sign_P"] == 0` при отсутствии ключа инвертировал знак.
   *Статус: исправлено.* Теперь инверсия только при `ok && sign == 0` (как
   `map.js:150`). Добавлен тест `TestMapTilePnetSignAbsent`.

6. Клиент форматировал всё через `toFixed(1)`, включая мощность и температуру →
   «1726.0», «35.0»; спека §9.1 п.8 ждёт мощность целым.
   *Статус: исправлено.* В `home.js` ячейкам мощности (`home.cell.p`) задан
   `decimals = 0` (целое Вт), остальные — 1 знак. SOC — целое %.

7. Палитра клиента расходилась со спекой §8.1 (`gray #9aa4a0` → `#999999`,
   `darkblue #7fa9d0` → `#2f6ea3`).
   *Статус: исправлено.* `home.js` (палитра `COLOR`) и `app.css` (`c-darkblue`,
   `c-gray`) приведены к спеке §8.1. Светлые вариации `red/orange` оставлены для
   читаемости на тёмной плитке (`red #e8837f`, `orange #e0902f`).

8. `Grid.I` красится `colorGridPower(iin)`, а ток сети беззнаковый → ветка `green`
   недостижима. Спеке §8.2 не противоречит.
   *Статус: оставлено.* Ток сети — величина (магнитуда, как в `map.js`), знак
   несёт мощность (`PNET_Sign_P`). Правило раскраски «I/P сети» (§7.1/§8.2)
   технически ведёт к `green` только для отрицательного — здесь недостижимого —
   значения; поведение намеренное, совпадает с `map.js`.
