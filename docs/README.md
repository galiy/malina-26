# Документация проекта «Микроарт-Малина»

ПАК «Малина» на Raspberry Pi 3: переработанный образ (Debian 12 bookworm,
immutable-root) с веб-админкой, сетью в двух режимах, наблюдаемостью.

## Карта документов

- [../requirements.md](../requirements.md) — требования к рефакторингу (что и зачем).
- [../deploy/restore.md](../deploy/restore.md) — восстановление системы на устройстве.
- [../image/README.md](../image/README.md) — сборка образа (pi-gen).
- [../web/README.md](../web/README.md) — сборка и структура веб-сервисов.
- [ui.md](ui.md) — **обзор веб-интерфейса (UI)**: вход, меню, навигация.
- [ui-pages.md](ui-pages.md) — **описание каждой страницы** UI и инструкции по настройке.
- [network.md](network.md) — **настройка сети**: полное описание режимов и параметров.

> `hardware.md` и `AGENTS.md` не коммитятся (в `.gitignore`); это локальные заметки.

## Кратко

- Устройство: `192.168.13.60` (режим «Точка доступа» — также `10.10.100.254`).
- Веб-админка: `http://<адрес-устройства>/`.
- **Логин по умолчанию: пользователь `malina`, пароль `malina26`.**
- Языки интерфейса: Русский, Беларуская, 中文, English (по умолчанию — English).
