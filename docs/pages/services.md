# Сервисы (`/services`)

![Сервисы](../img/services.png)

- Вкладки **«МАЛИНА»** (службы подсистемы, можно запускать/останавливать) и
  **«Системные»** (только просмотр).
- Колонки: служба, описание, состояние (бейдж), действия, комментарий.
- **Запустить/Остановить** доступны только для служб вкладки «МАЛИНА» (список
  фиксирован). Системные службы — только для чтения.
- Колонка **«Комментарий»** показывает категории:
  - критичные для ОС — «не останавливать»;
  - ядро сети (`malina-net`) — «остановка разорвёт сеть/AP»;
  - сама админка (`malina-web`) — «остановка закроет UI»;
  - таймеры — «работает по расписанию»;
  - управляемые скриптами — «не запускать вручную».
- Вверху — кнопка **«Перезагрузить малину»** (с подтверждением).
- Таблица автообновляется (раз в 5 секунд).

## Ожидание перезагрузки

После нажатия «Перезагрузить малину» открывается страница с прогресс‑«градусником»
на 2 минуты и надписью «Ожидание перезагрузки малины…». Каждые 5 c страница
пытается переподключиться; при успехе — переход на главную. Если за 2 минуты не
удалось — «Упс… Что‑то пошло не так, после загрузки малины — обновите страницу»,
таймер останавливается.
