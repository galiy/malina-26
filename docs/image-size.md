# Размер и упаковка публичного образа (8-ГБ SD)

Технический расчёт для варианта 3 (релизный образ с p3 и раскладкой).
Сам вариант и последовательность сборки — `deploy/local-deploy.md`.

## Измеренная карта

На `.68` стоит китайская карта с реальной ёмкостью:

```
7 917 797 376 байт = 7,37 ГиБ
```

Номинал «8 ГБ» — это 8 000 000 000 байт (7,45 ГиБ), фактическая ёмкость всегда
меньше. Карты одного номинала различаются; расчёт ниже оставляет запас.

## Раскладка

| Раздел | Размер |
|---|---|
| p1 boot | 512 МиБ |
| p2 root | 3 ГиБ |
| p3 `/malina` | **3 ГиБ** |
| **Итого образ** | **6,51 ГиБ** (6 988 759 040 байт) |

Запас на измеренной карте: **929 038 336 байт ≈ 0,87 ГиБ (11,7%)**.
Образ 6,51 ГиБ влезает и в карты с реальной ёмкостью ~7,2 ГиБ.

`MAL_EXTRA_GB=5` для публикации не использовать: итог ~8,5 ГиБ, карта не влезет.

## Сборка

```bash
IMG=/opt/raspberry_tmp/pi-gen/deploy/2026-10-19-malina-lite.img
MAL_P3_GB=3 deploy/local/deploy-local.sh "$IMG"
```

`MAL_P3_GB` задаёт точный размер p3 для файла-образа (приоритетнее
`MAL_EXTRA_GB`). Для блочного устройства поведение прежнее: p3 из остатка карты.

## Проверка

```bash
ls -l --block-size=1 "$IMG"
sfdisk -d "$IMG"
```

Ожидаемо:

- размер файла ≤ 6,6 ГиБ;
- три раздела: p1, p2, p3;
- p3 монтируется как `/malina`;
- артефакты и `manuals/` на месте, `malina-web` стартует.

## Архив для Windows

Windows нативно открывает **ZIP**, поэтому публикуется `.img.zip`. Внутри файл
больше 4 ГиБ — используется ZIP64; Проводник Windows 10/11 его открывает.
Raspberry Pi Imager умеет писать `.zip` напрямую; Win32DiskImager требует сначала
распаковать.

```bash
zip -9 malina-<версия>-rpi3-8gb.img.zip "$IMG"
```

Фактический размер ZIP — **803 444 249 байт (766 МиБ)**; зависит от заполнения p3. Сырой `.img` на
сервер публикации не выкладывать — только ZIP.

Проверка на VPS: свободно ~2,5 ГиБ; ZIP 766 МиБ помещается, старые версии удалять; собирать архив на VPS
нельзя — нужны одновременно `.img` и `.zip`, а места для этого нет. Архив
собирается локально/в CI, на сервер заливается только готовый файл.
