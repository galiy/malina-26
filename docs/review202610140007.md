## Сводка

Реализация добавляет второй (raw) инстанс `malina-tsdb` на tmpfs (`/run/malina-ts-raw`, 200 МБ,
retention 48 ч, row-раскладка сегмента), модуль сохранения сырья в пулерах (`lib/stat` +
`lib/tsdbclient`), аккумулятор телеметрии в `malina-web` (усреднение raw → avg-tsdb) и
страницу настройки аккумулятора в «Параметрах системы».

**Сборка, `go vet`, `go test ./web/... ./daemons/...` проходят чисто.**

Соответствие артефактов соблюдено:
- документация `docs/telemetry-store.md` §14, `docs/accumulator.md`, `docs/stat.md` присутствует;
- контракты `map` (26 полей), `kes` (15), `mbms` (3n) в `tscontract` согласованы с `publish_raw.go`;
- i18n — паритет по всем 8 локалям (ru, be, zh, en, ka, kk, uz, tg);

## Замечания и статус устранения

1. **Совместимость wire-протокола** — **исправлено.** Добавлен
   `daemons/tsdb/wire_client_test.go` (`TestWireCompatClientServer`): round-trip
   `EncodeWriteReq`/`EncodeReadReq` клиента через серверные `decodeWriteReq`/`decodeReadReq`,
   а ответов сервера — через `ParseReadReply`. Протокол §10 теперь защищён двусторонне.

2. **`c.Fields()` в цикле** — **исправлено.** `accumulator.go:122` выносит `fields := c.Fields()`
   до цикла по полям.

3. **Сортировка `samples`** — **исправлено.** `accumulator.go:115-116` копирует выборку и
   сортирует по `Time` перед взятием «последнего» снимка.

4. **`stat.Sink.Close()` не ждал горутину** — **исправлено.** Добавлен `sync.WaitGroup`;
   `Close()` теперь `close(done)` + `wg.Wait()` (финальный `flush` гарантирован).

5. **Источник смещения в `row.go`** — **исправлено.** `readSegmentRow` использует
   `pos := int(ref.hdrSize)` единообразно с `ref`.

6. **Мёртвая ветка в `Run`** — **исправлено.** Цикл переписан: `windowEnd := now.Truncate(period)`,
   `fire := windowEnd.Add(5s)` + `time.Sleep`; недостижимая ветка `next.After` убрана.

Остальные замечания носили информационный характер:
