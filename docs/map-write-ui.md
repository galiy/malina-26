# UI записи в МАП (G1) — требования

Статус: **v1 реализовано** (вкладка «Управление» на `/map`; **см. также**
`docs/map-write.md`, `docs/map-write-api.md`; данные — `control-data.js`,
генерируется `web/tools/gen_control.py` из `~/src/mapsettings/catalog.json` + легаси-набора;
логика — `web/assets/static/control.js`; запись — `POST /api/map/write`).

Ограничения v1 (на доработку):
- Подсказка «?» — пока простой `alert(name + desc)` (улучшить до оверлея).
- `0x1B1`/`0x1B6` отсутствуют в каталоге: `0x1B6` — время (обрабатывается особо),
  `0x1B1` — имя-заглушка (уточнить по доку).
- Масштаб — по легаси-формулам; min/max/единицы/подсказки — из каталога (сверить
  параметры, зависящие от напряжения 12/24/48/96).

Состояние команд:
- **ON/OFF** — по `MODE_RAM` (`>=2` — включён; `0/1` — выключен).
- **Charge** — включён ⇔ `MODE_RAM==4 (M_ONCHARGE)` **и** `StatusCh!=0`; тумблер шлёт
  `charge_off`, если заряд идёт, иначе `charge_on`.
- **Реле** — доступны при `LCD_ReleN_Funk==8`, состояние — биты `Status_RELEdop` (`0x586`).

Таб **«control»** на странице `/map`. Пишем через **`/api/map/write`** (cookie-сессия).
Никаких внешних метаданных — **хардкод** реестра параметров в UI.

## 1. Согласовано

- Объём — **только безопасный whitelist** (параметры легаси-редактора), не «любая ячейка».
- **Переключатели** (состояние): MAP ON/OFF, Charge ON/OFF, Реле1..N.
  **Кнопка** (моментальная, без состояния): **Reset**.
- **Подтверждения:** **Reset — тройное**; **MAP OFF — однократное**; всё
  остальное (ON, Charge, реле, параметры) — **без подтверждения**.
- **Валидация ввода — на клиенте**, по официальной документации МАП.
- Масштабирование воспроизводим как в легаси — **детально по каждому параметру**.
- После записи **отдельно API не читаем**: страница и так пулит раз в секунду,
  ждём следующего обновления (запись синхронная, shm уже обновлён).
- UX делаем свой (легаси не нравится). Все параметры — из легаси.
- `manuals/` — отдельная страница про редактирование.

## 2. Типы параметров → виджет / масштаб / валидация

`raw` — значение в ячейке; `k = eeprom[0x06]` (биты `_UACC`, делитель напряжения).

| Тип | Виджет | Показ (raw → экран) | Ввод (экран → raw) | Единица |
|---|---|---|---|---|
| `list` | select | `raw` (0..N) | `raw = v` | — (подписи из дока) |
| `number` | число | `raw` | `raw = v` | — |
| `sec` | число | `raw` | `raw = v` | сек |
| `dc` | число | `(raw<<k)/10` | `raw = (v*10)>>k` | В |
| `dc_dop` | число | `(raw<<k)/10`, доп `dop` | `raw=(v*10)>>k`, `dop=v*10-(raw<<k)` | В |
| `power_dop` | число | `(raw<<dop)*100` | `raw=v/100` (+`dop`) | Вт |
| `ac` | число | `raw+100` | `raw = v-100` | В |
| `temp` | число | `raw-50` | `raw = v+50` | °C |
| `capacity` | число | `(raw<<k)/25` | `raw = (v<<k)/25` | А·ч |
| `current_c` | число | `raw/100` | `raw = v*100` | ×C,A |
| `time` | time | `(raw>>3):((raw&7)*10)` | `raw=(hh<<3)+round(mm/10)` | — |
| `charge_time` | число | `raw*16/60` | `raw = v*60/16` | часы |

Диапазоны (min/max/step) и подписи `list` — из официальной документации MAP
(легаси брал их из mapd; у нас — хардкод из дока). Для `12/24/48/96 В` часть
границ зависит от напряжения системы.

## 3. Вариативность по модели

- **Реле:** Титанатор — **3 реле** (1/2: `0x198..0x19F`; **3: `0x120..0x123`,
  `_LCD_Rele3_Funk/L1/L2/Gist`**); Доминатор — 2; остальные — **0**. **Реле4 не делаем.**
  Доступность реле = mode-ячейка (`0x198`/`0x19C`/…​) == `8` («внешнее управление»).
  Управление/состояние — ячейка **`0x586`** (`_Status_RELEdop`): `relay1`=бит0,
  `relay2`=бит1, `relay3`=бит2 (`S_RELE3`).
- **Сеть:** группу «Сеть2» **показываем активной** (не скрываем), как в легаси.
  Прочую модельную вариативность **пока не вводим** — как в легаси; отдельной задачей позже.
- **Напряжение** 12/24/48/96 В — влияет на границы части параметров (из дока).
- Подпараметры реле (`0x199/0x19A/0x19B`, …) — **плавающий тип**: зависят от значения
  функции (`0x198`): `relay_mode_on/off/hysteresis` (off|sec|dc|temp|time|list).

## 4. Команды (низ формы)

- Переключатели: **MAP ON/OFF** (команда `0`: 2/1), **Charge ON/OFF** (`5`/`4`),
  **Реле1..N** (`0x586`, биты 0/1/2). Показ текущего состояния — из пула страницы.
- Кнопка: **Reset** (`0`, код `6`) — **тройное подтверждение**.

## 6. Подтверждения

- **Reset** — тройное подтверждение.
- **MAP OFF** — однократное подтверждение.
- Всё остальное (ON, Charge ON/OFF, реле, параметры) — **без подтверждения**.

## 7. Макет вкладки и поведение

- Вкладка «control» разбита на **группы**:
  1. **«Управление»** — все команды (переключатели ON/OFF/Charge/Реле1..N, кнопка Reset).
  2. Далее — **группы изменяемых параметров** (как в легаси), каждая — **таблица**.
- Колонки таблицы:
  1. **Название** + иконка **«?»** (детальное пояснение).
  2. **Текущее значение** — только чтение; обновляется по событию **raw** (пул страницы).
  3. **Контрол редактирования** (по типу: число / выбор / чекбоксы…).
  4. **Единица измерения**.
  5. **«Сохранить»/«Отменить»** — появляются, когда значение **изменено и валидно**.
- Контрол в колонке 3 обновляется из raw **только если пользователь не менял** значение;
  изменённое — **подсвечено**, невалидное — **красным**.
- **«Отменить»** в строке — вернуть текущее значение и возобновить обновление колонки 3.
- Сверху страницы — **«Сохранить всё»** и **«Отменить всё»**.
- После сохранения **одного** параметра — **принудительно** запрашиваем raw и обновляем
  всё, **даже если** чекбокс «отключить обновление» включён.
- **«Сохранить всё»** — пишем все изменённые; raw запрашиваем **один раз в конце**
  (не после каждого параметра). Один запрос на устройство, если порог (≤64 оп.) не превышен;
  в контексте страницы всегда **одно** устройство.
- Своего пулера у вкладки нет — кормимся штатным пулером `/map` и его чекбоксом
  «Отключить обновление». Состояние **контролов команд** (ON/OFF, Charge, Реле) обновляется
  из того же raw-потока, с той же логикой «не трогали / изменили», где применимо.

## 8. Источник названий/диапазонов/подсказок

Берём из проекта **`~/src/mapsettings`** — `catalog.json` (209 параметров):
`key, cell, addr, width, kind, access, name, group, modes, unit, scale, offset,
min, max, desc, enum, fields`. Генерируем из него статику для нашего web
(аналогично `mapfields.go`). Набор отображаемых/редактируемых групп — по легаси (whitelist).

## 9. Решения

- Набор — **только легаси** (36 параметров); каталог `mapsettings` используется лишь
  для названий/диапазонов/единиц/подсказок.
- «Сохранить всё» — **один запрос** на устройство (одно устройство в контексте страницы),
  если число операций ≤ 64 (иначе авто-разбиение).
- Чекбокс «Отключить обновление» — **существующий** на `/map`; у вкладки своего пулера нет.
- Состояние контролов команд обновляется из общего raw-потока (та же логика, что у параметров).
