# КЭС: НЕПРИНЯТАЯ / непроверенная информация

Всё, что **не** входит в два источника истины (карта
`Карта Памяти_MPPT_WG_2021_01_18.xlsx` и наши подтверждённые ячейки — см.
`docs/kes-memory.md`). Опираться на это можно только как на гипотезы.

## 1. Неизвестные адреса
- **`0x0A`** — проверено: на `Версия Модели` не влияет (ячейка «Версия Модели» не найдена).
- **Задержки реле** (`×30 сек`) — адрес не найден.
- **Пороги `T Вкл/Вых`, токи/ёмкость АКБ** — адреса не найдены (`0x000..0x1FF`).

Недокументированные ячейки (из дизасма `mpptd`/JSON `read_json`; **не подтверждены** двумя
источниками истины): `Mode` = `0x2C2`, `Sign` = `0x37A`, `MPP` = `0x379`, `windspeed` = `0x3F8`.
Из контракта/реализации `kes-reader` и из `kes-memory.md` **убраны**. `kes-emu` (сторона
устройства) по-прежнему эмулирует их как legacy-поведение — вернуть в «правду» при подтверждении.


## 2. Прочее (из legacy, не подтверждено)
- **Модели/версии** (200/100, 250/60, 200/60; пороги FW) — из паспорта/invertor.ru/MAP2Gui,
  не подтверждено.

## 3. Метод разведки (как получали подтверждения)
- `kes-emu` заполняет EEPROM диапазонами/сериями значений (временные входные файлы больше
  не храним); подтверждённые ячейки не затираются.
- Контроль — по полям монитора `MAP2Gui` (Wine, порт = эмулятор).
