# КЭС (MPPT): карта памяти и настроек

Регистровая карта солнечного контроллера КЭС (MPPT, Микроарт) — измерения (RAM) и
настройки (EEPROM + RAM-копии). Связано: `docs/kes-reader.md` (контракт `kes-reader`),
`docs/legacy/kes-legacy-malina2.md` (разбор legacy), `docs/map-memory.md` (карта МАП).

## 2. Модели и версии КЭС

| Модель | Uвх макс, В | Iзар макс | Макс. мощность СП (12/24/48/96 В) | Вес | Примечание |
|---|---|---|---|---|---|
| **200/100** | 200 | 100 A @40°C | 1350 / 2750 / 5500 / 11000 Вт | 5 кг | старшая |
| **200/60** | 200 | 60 A @40°C | 810 / 1650 / 3300 / 6600 Вт | 3,7 кг | младшая PRO |
| **250/60** | 250 | 60 A @40°C | 810 / 1650 / 3300 / 6600 Вт | 5 кг | 250 В вход |

- Линейки: **PRO** и **DOMINATOR** (у обеих реле 3,5 кВт / 240 В 16 А, 3 шт.).
- Модель `100/20` (100 В / 20 А) — **без связи с МАП** (для `kes-reader` не подходит).
- **Тип АКБ:** кислотные, GEL/AGM, AGM-Shoto, AcidTrojan, Li-Ion 3.7/3.9 (для Li — нужен
  BMS); допускается 12/24/48/96 В.
- Данные модели различаются током заряда и пределом входа; **регистровая карта общая**.

## 3. Чтение из RAM («Монитор»)

- Любой RAM-адрес из таблиц ниже **для чтения** требует **+ `0x1F0`** (например
  `Vc_PV 0x2D9` → читать `0x4C9`), правило из карты MPPT.
- Нативно `mpptd` читает окнами: `0x0000`(190 Б), `0x02C2`(240), `0x04B2`(240),
  `0x05A3`(240); при этом `адрес_устройства = RAM-адрес + 0x1F0`,
  `смещение_в_образе == RAM-адрес` (см. legacy-док §1b).
- Формат величин: `"12,34"` = 1234 (сотые); температуры обычно `x-50` (кроме явного °C).

## 5. Меню настроек КЭС (структура, паспорт)

Главное меню (FW ≥ 6.0):
1. **Установки аккумулятора** — Тип, Емкость, Uцикл. заряда, Uбуфер, Uстарта заряда,
   Макс. ток заряда, Темп. коэффициент.
2. **Связь МАП/BMS/MPPT** — Выбор направления (Ведомый / Главный MPPT / Главный MPPT+BMS),
   Выбор адреса/кол-во ведомых MPPT.
3. **Заводские установки** — Сброс настроек, Версия ПО.
4. **Калибровка** — ВДТ (Датчик Тока), ВГ (Датчик Оборотов Ветрогенератора).
5. **Установки дисплея** — Скорость бегущей строки, Яркость, Время подсветки (1..98, 99=пост.),
   Время индикации (0..99 с).
6. **Индикация** — 5 страниц: Авто / Ручн / Выкл.
7. **Режимы работы** — Поиск ТММ (Авто/Ручной), Тип стабилизации (резерв), Период сканирования
   (2..10 мин), Параллельное включение, Тип Источника (Солнце/Ветер).
8. **Установки источника** — Кол-во панелей послед./паралл., Ток КЗ, Uхх, Uмпп, Iмпп.
9. **Пороговые напряжения** — Uакб вкл/выкл, Мощность СП1/2/3 вкл, Режим экономии.
10. **Установки реле** — Выкл / Ошибка / Напряжение АКБ / Мощность СП / Внешн. Кулер (FW≥6.1).

Особенности: настройки МАП для КЭС — «Б/Диз.Генер./BMS MPPT» → «MPPT (C)mART» и
«Кол-во подкл. MPPT»; **ПО МАП ≥ 21.0**. Реле 3 шт; включение по избытку мощности — по
приоритету реле 1→2→3; поддержаны прямой/инверсный режимы.

### 6.1. Дополнительные ячейки из паспорта (FW ≥ 6.1)
- **Задержка включения реле:** EEPROM **`0x0083`**, единица = **30 с**.
- **Задержка выключения реле:** EEPROM **`0x0087`**, единица = **30 с**.
- «Внешн. Кулер» — режим реле (порог >50 °C, возврат <40 °C, только FW≥6.1).
> Адреса `0x0083`/`0x0087` в `Карта Памяти_WG.csv` не значатся и могут пересекаться с
> `OVR_P[1..2]` — это **разные версии прошивки**; сверить на конкретном FW.

## 7. Ошибки `RSErrSis` (0x3B6), биты

0 — Перенапряжение панелей; 1 — Перенапряжение АКБ; 2 — Переразряд АКБ;
3 — Короткое замыкание АКБ; 4 — Перегрев АКБ; 5 — Ошибка связи I2C; 6,7 — н/о.
`I2C_Err` (0xD5A): 0 Ack, 1 Sum, 2 Data Size, 3 Protocol, 4..7 н/о.

## 8. Внешние датчики и ветер (паспорт)

- **ВДТ №1/№2** (внешние датчики тока): калибровка при токе СП ≥ 5 А; «−» ВДТ №1 → «+» АКБ
  (контроллер ветрогенератора), «+» ВДТ №2 → «+» АКБ (инвертор); при параллельном включении
  все ВДТ №2 на один провод к инвертору. Ток/мощность — `I_EXTS*/P_EXTS*` (§4).
- **Ветрогенератор** — только с доп. блоком №2 (напряжение ограничения 85..180 В, джамперы);
  обороты — сигнальный кабель «Датчик Оборотов». Обороты — `windspeed` (0x3F8).

- Измерения — §4 (все поля; `Mode/Sign/MPP/UID/windspeed` — из дизасма).
