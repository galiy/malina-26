# Grid-reader: плашки, таблицы, графики

**Статус:** реализовано 2026-10-18 (плашки, таблицы, графики, сравнение). Страница инвертора, карточки статуса настроек и исправление GRID в статистике добавлены и проходят отдельный цикл ревью (3 раунда, блокеров нет); задеплоено на дефолтное устройство.

Источник данных: контракт `grid` v1 (`docs/grid-reader.md`). Плашки — из shm
(живые данные), таблицы/графики — из tsdb (raw/avg). `energy_today`/`energy_total`
есть только в shm; в tsdb не пишутся.

## 1. Плашки на главной

### 1.1. Раздел

- Раздел **«Сетевые»** на главной, отдельные плашки по инверторам.
- Плашки **сгруппированы по размещениям** («Дом», «Гараж», …).
- Сумм по размещению нет.
- Если инверторов нет или опрос выключен — **раздел скрыт**.
- Внутри размещения сортировка **по имени**.
- Обновление — **раз в 5 секунд**.

### 1.2. Состав плашки

Заголовок: имя оператора + тип/заводской серийник. Размещение — заголовок группы.

Крупно:

- **AC активная мощность** — поле 7;
- **суммарная PV-мощность** — поля 3 + 6.

Мелким списком:

| Что | Источник |
|---|---|
| напряжение PV — максимум | max(1, 4) |
| ток PV — сумма | 2 + 5 |
| реактивная мощность AC | 8 |
| частота сети | 9 |
| напряжения фаз L1/L2/L3 | 10, 12, 14 |
| сумма токов фаз | 11 + 13 + 15 |
| температуры | 16, 17 |
| выработка сегодня | 25 (shm) |
| выработка всего | 26 (shm) |
| время последнего успеха | shm `LastSeen` |

- `inverter_status` (18) — **текстом по-русски**, с локализацией.
- Аварии (19–24): если любое слово ненулевое — **восклицательный знак слева
  вверху**, как у БМС. Без списка кодов и без раскрытия.
- Подписи и строковые значения — русский источник + локализация на 8 языков.

### 1.3. Состояния

- stale / offline / бан: плашка **остаётся** с последними значениями,
  приглушается, показывает статус и время последнего успеха.
- Цветовых порогов по значениям нет; цвет только у статуса и значка аварии.

## 2. Таблицы

- Отдельная закладка на инвертор, как у остальных устройств.
- Колонки — **все 24 хранимых поля** контракта `grid` v1.
- Имена колонок локализованы; при нажатии/наведении — **подсказка с описанием
  поля**, как в остальных таблицах.
- `alarm_w0..w5` — **hex** (`0x0001`), без расшифровки кодов.
- `temperature_1`/`temperature_2` — подписи по типу:
  - Deye: IGBT / радиатор;
  - Sofar: модуль / внутренняя.
- Энергии (25/26) в таблице **нет** — её нет в tsdb.
- Экспорта CSV/копирования **нет**, как у остальных таблиц.
- Источник raw/avg, периоды, сортировка, лимиты — как у остальных таблиц.

## 3. Графики

### 3.1. По устройству

Закладки по инверторам, как у остальных устройств. Наборы:

1. **Все напряжения**: 1, 4, 10, 12, 14.
2. **Все токи**: 2, 5, 11, 13, 15.
3. **Все мощности, включая реактивную**: 3, 6, 7, 8 + вычисляемая сумма PV
   (3+6) отдельной линией.
4. **Частота и температуры**: 9, 16, 17.

- В наборах со смешанными единицами (мощности: Вт/вар; частота/температуры:
  Гц/°C) — **одна ось Y**, единицы в легенде.
- Графиков энергии нет.
- Графика статуса/аварий нет.
- Пороговых линий нет.

### 3.2. Сравнение инверторов

Отдельный режим вдобавок к закладкам:

1. **Активные мощности** — линия на каждый инвертор (поле 7).
2. **Реактивные мощности** — линия на каждый инвертор (поле 8).
3. **Сумма активных**: общая сумма всех инверторов + сумма по каждому размещению.

Вёрстка, связанность курсора, зум, управление, хинты и общий код — **как на
остальных графиках**.

## 4. Общее

- Единицы и точность: В — 0,1; А — 0,01; Вт/вар — 10; Гц — 0,01; °C — 0,1;
  кВт·ч — 0,1.
- Локализация: ru, be, zh, en, ka, kk, uz, tg; источник строк — русский;
  дефолт — английский.
- Главная обновляется раз в 5 с.
