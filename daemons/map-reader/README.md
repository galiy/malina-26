# map-reader — демон опроса МАП (Микроарт)

Отдельный Go-демон ПАК «Малина». Ищет подключённые МАП на последовательных
портах, захватывает найденный порт и опрашивает устройство. Список активных МАП
публикует в **разделяемую память** (для внешнего API `map-list` в `malina-web`),
команды принимает **синхронно** через Unix-сокет.

Демон не поднимает HTTP и не ходит по сети: обмен с остальными сервисами —
только локальный (shm + unix-сокет).

## Как работает

1. Главный поток (`scan`) перебирает свободные последовательные порты и короткой
   пробой (≤ ~2 с) определяет МАП: протокол **Микроарт** (приоритетный), затем
   **Modbus-RTU**; скорости **115200 → 19200 → 57600 → 9600** (38400 нет).
2. Найденный порт захватывается (fd остаётся открытым), МАП попадает в список,
   запускается горутина опроса `poll`.
3. Список и телеметрия публикуются в POSIX shared memory **бинарно** (seqlock):
   компактные записи списка + слоты с контрактом `MapData`. Горутина опроса
   обновляет признак присутствия; при потере порта (нет ответа `max-miss` = 9
   неудачных попыток подряд; ретраи в цикле считаются попытками) МАП убирается из списка.

### Признаки МАП

Страница `0x00..0x2F` ячеек; МАП, только если все условия (см. `docs/map.md`):

- `_Device (0x00) == 3` (у КЭС/MPPT — `0x05`);
- `_VerPO (0x02) != 0`;
- `_DevOpt (0x07) ∈ {1,3}` (значение `2` — снят с производства, не берём);
- валидный кадр (сумма/CRC).

Модель (буква): `_DevOpt==3` → **T**; иначе `0x24&1` → **D**; иначе `0x01&0x80`
→ **H**; иначе **P**.

## Принципы чтения регистров

Несколько регистров, расположенных недалеко друг от друга, читаем **одним
заходом**, расширив область, а не двумя отдельными запросами (меньше обменов и
тайминговых рисков):

- объединяем запрошенные ячейки в смежные интервалы; небольшой зазор между ними
  дешевле перекрыть одной страницей, чем делать второй обмен;
- лимиты одной посылки: нативный протокол — страница `P 0..255` (1..256 байт);
  Modbus `0x03` — до 125 регистров (250 байт);
- если суммарный интервал превышает лимит — делим на минимальное число страниц.

Так уже сделано в пробе: страница `0x00..0x2F` снимает `_Device`, `_VerPO`,
`_DevOpt`, `_SyncDiz_Plat` и серийник за один обмен.

## Обмены

- **Shared memory:** `/dev/shm/malina-map-state`. Бинарный сегмент
  `[header 64B][list: 9×72B][slots: 9×slotSize]`: компактный список (`ListItem`)
  и слоты с контрактом `MapData`. Читает `malina-web` (`maplist.go:DecodeList`,
  `contract.go:DecodePayload`). Формат — `docs/map-contract.md`.
- **Управление:** Unix-сокет `/run/malina-map/control.sock`.
  Запрос — одна JSON-строка `{"cmd":"…"}\n`, ответ — JSON-строка. Команды:
  `ping`, `list`. Синхронно, по одному запросу на соединение.

## Параметры

Все параметры **зашиты в код** (`main.go`, блок `def*`); единственная настройка —
режим отладки:

- `-debug` — подробный лог (попытки проб, пропуски портов). По умолчанию выкл.

Значения: опрос `1s`, потеря `10` промахов, скан `10s`/`1m`, backoff
`30s`/`10m`, максимум `9`; shm `/dev/shm/malina-map-state`, сокет
`/run/malina-map/control.sock`.

## Тест на эмуляторе (без железа)

`test/fakemap.py` поднимает PTY и притворяется МАП (Титанатор, serial 51510,
протокол Микроарт, 115200), отвечая на чтение **любой** страницы с побайтовым
эхо. Демон сканирует только стандартные пути, поэтому на тестовом хосте
пробрасываем псевдопорт под одним из них:

```sh
python3 test/fakemap.py &                      # создаст /tmp/kilo/fakemap
sudo ln -sf /tmp/kilo/fakemap /dev/serial0     # попадёт в стандартный шаблон
make host
./dist/map-reader -debug
# в логе: "МАП найден ... модель=T serial=51510a"
```

Проверить список:
`python3 -c 'import socket;s=socket.socket(socket.AF_UNIX);s.connect("/run/malina-map/control.sock");s.sendall(b"{\"cmd\":\"list\"}\n");print(s.recv(4096))'`.
Остановка эмулятора → МАП исчезает из списка через `max-miss` (9) неудачных попыток.

## Сборка и установка

```sh
make arm      # dist/map-reader-armv7 (Linux/armv7, статический)
```

Бинарник кладётся в `/malina/usr/local/sbin/map-reader`, юнит
`map-reader.service` — в `/etc/systemd/system/` (см. `deploy/manifest.tsv`,
`deploy/provision.sh`).

Пере-деплой на устройство (сборка → scp → установка → enable/restart):

```sh
MALINA_PASS=<пароль> daemons/map-reader/deploy.sh root@<host>
```

> Запись в МАП (`w`, `ComMAP_*`) запрещена без явного разрешения; демон по
> умолчанию только читает.
